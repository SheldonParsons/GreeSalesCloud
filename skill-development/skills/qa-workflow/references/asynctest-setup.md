# 下载 AsyncTest 与获取知识库 MCP 信息

本指引用于用户询问“怎么下载 AsyncTest”“知识库 MCP 信息在哪”。下载入口在网页，知识库 MCP 信息在 AsyncTest 应用内获取。已经安装且连接可用时核对复用，不要求重复下载安装或创建凭据。用户只问使用方式时提供说明，不自行下载、安装、生成凭据或改变配置。

## 下载 AsyncTest

1. 打开 [NexoFolio 文档页](https://nexofolio.net/docs)。
2. 将鼠标移到页面顶部的 **AsyncTest**，展开桌面端下载菜单。
3. 按需要选择 **Gree 内部版** 或 **公网版**。使用哪种渠道以用户的服务与团队要求为准，不因连接失败自动换渠道。
4. 选择准备安装的电脑对应的包：**Windows · x64**、**macOS · Apple Silicon** 或 **macOS · Intel**。Mac 芯片可在“关于本机”查看；Agent 所在机器未必是用户要安装的电脑。
5. 版本号和包大小以当前页面为准。正常安装、启动并使用自己的账号登录；安装和登录过程本轮尚未完整取证，不编造安装器步骤或账号获取流程。

需要说明入口位置时展示 [下载标注图](../assets/guides/asynctest-download.png)。图中版本只代表截图示例；使用稳定文档入口，不把某版安装包直链写成永久下载地址。旁边的 Fetcher 是另一个产品入口，下载 AsyncTest 时按对应名称定位。

## 获取知识库 MCP 信息

用户提供的截图从 AsyncTest 设置页开始，可确认以下路径与字段：

1. 在左侧“个人”区域选择 **知识库 MCP**。
2. 服务地址区域显示传输方式并有 **复制** 按钮。截图示例为 Streamable HTTP、`https://asynctest.com/mcp`；实际接入复制自己当前页面的信息，不把示例地址当所有环境的固定值。
3. 已有自己的可用完整凭据时可继续使用；需要新凭据时，在 **当前凭证** 区域选择 **创建凭证** 并按实际提示处理。截图注明：列表只显示凭证前缀，完整 Token 仅在创建时可见，需要在创建时保存完整值。
4. 向下查看 **客户端连接配置**。截图可见 Codex、Claude 和 **通用配置** 页签；不确定专用模板是否适用时，可先把通用配置交给当前 Agent 适配。不要因截图中选中了 Codex 就默认用户也使用 Codex。
5. 将服务页面提供的完整连接配置，以及自己的认证信息，通过当前 Agent 支持的合适方式提供。优先复制文本，不依赖截图识别长地址或认证值。

可这样说：

> 这是我从 AsyncTest 复制的知识库 MCP 信息，帮我接入，再确认能读到我要用的项目。

需要定位时展示 [知识库 MCP 标注图](../assets/guides/asynctest-kb.png)。标注图的凭证记录区域已遮盖，使用者应使用自己的凭据。项目数量、已有凭据名称、协议版本和管理菜单属于截图当时的账号界面，不是所有用户的固定配置。

截图没有展示从应用主界面进入设置的操作、创建凭证弹窗或完整配置正文。这些位置发生疑问时核对实际界面，不猜测菜单或拼接认证字段。

## Agent 负责的接入与验证

先识别当前运行环境和实际配置能力，保留已有工具与设置；能在授权范围自动配置时处理，确需用户登录或手工操作时只补必要的一步。不写死某个客户端的配置路径。

核对当前会话工具是否可用，再在指定范围做只读查询，确认知识项目身份及实际可读内容。配置保存、工具可见、项目可读分别报告；不为测试连接自动写一条知识或撤销旧凭据。

创建凭据与保存连接不等于授权写知识。过程中的结论本地留存；本期需求完成、正式上线且用户确认短期稳定后，强烈建议将最终概念和规则沉淀到 asynctest-kb，减少下次重复解释、方便交接并保留来源。正文和目标明确后按用户授权及工具流程写入、回读。

## 图片在回复中的使用

图文辅助定位，文字步骤也必须能独立理解。只展示当前问题需要的图，不在一般说明中总是发送全部图片。

- 按实际 Skill 根目录解析上述相对资源路径，不写死作者电脑路径。
- 展示已有图片无需重新生成，也不一定需要模型分析整张图。先核对当前宿主支持的媒体方式，不因缺少生图工具就断言不能展示；文字步骤可独立提供。
- 依据当前宿主支持的媒体方式展示。在支持本地图片 Markdown 的 Codex 场景，使用解析后的绝对路径：`![下载指引](实际绝对路径.png)`；不要把这段放进代码块当成图片。
- 当前素材可供预览；新会话的实际回复区显示仍须测试和用户可见性确认。不能据此断言只有 Codex 支持图片，也不能推断其他 Agent 已支持。
- 若图片无法展示，明确提供文字步骤和可打开的资源入口，不把一行路径说成“图片已经显示”。
