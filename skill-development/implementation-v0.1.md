## 已实现范围

| 设计 | 本版实现 | 限制 |
| --- | --- | --- |
| 1.1 身份与归属 | 工作空间、项目、系统、跨项目需求引用；同号需求独立保存 | 不自动迁移现有目录或合并外部平台对象 |
| 1.2 共享与差异 | 固定版本引用、适用范围、允许覆盖的配置字段、任务引用版本变化提示 | 不自动判定业务规则冲突或批量更新用例 |
| 1.3 状态与恢复 | 阶段、任务、结果、同步分开记录；不可变历史、摘要校验、过期写入拒绝；未知操作回查记录 | 状态与证据登记不代替业务验收 |
| 1.4 协作 | 任务负责人、同轮场景防重叠、显式资源占用、资源代次检查、交接前阻塞检查 | 合作式登记，不是身份认证或强制浏览器隔离；不调用宿主会话工具 |
| 1.5 信息保全 | 内容快照、归档标记、可重建索引、清单备份、校验、新目录恢复及恢复后核对状态 | 本地明文备份；未实现异地同步、定时备份、加密或跨格式迁移 |

数据格式采用 JSON v1，运行仅用 Python 3.11+ 标准库。工作状态位于用户工作目录，工具拒绝在 Skill 包内初始化用户空间。历史保存后再原子替换当前记录，写入由短时文件锁串行协调；锁残留不会自动抢占。

文件权限、原子替换和硬链接在本机文件系统完成验证。Windows、网络盘、其他宿主及硬件掉电行为尚未验证。格式不受支持时停止写入并保留原数据，不伪造兼容迁移。

正文中的图片需分别登记为快照。备份覆盖受管状态、历史修订和已登记快照，不自动包含未登记文件、来源后续修改或在线服务数据；成功回执报告覆盖范围和缺口。恢复只进入新的目录，不覆盖原工作空间，不重放业务写操作。

## 验证依据

在 macOS arm64、Python 3.11.9 上完成：

- 20 项行为测试：跨项目同号需求、共享范围与固定版本、过期写入、模拟保存中断、两个 CLI 写入竞争、来源快照与执行上下文固定、资源交接、未知动作不重派发、结果与同步分离、快照损坏、部分备份、恢复、归档、索引重建、路径越界与篡改等。
- 29 次公开 CLI 调用的虚构完整流程：两项目接入、共享配置差异、任务与结果登记、待核实动作、备份、恢复、核对、交接、摘要；没有发任何真实业务请求。
- 从打包 ZIP 解压到另一目录，用普通 Python 启动 CLI，完成初始化、创建项目和读取，验证不依赖本仓库路径。
- Skill 创建工具的格式检查通过；Markdown 相对链接检查通过。

格式检查器依赖的 PyYAML 仅安装在本机 `.local/qa-skill-validation-venv`，不是 Skill 运行依赖。未使用子代理，未验证独立 Agent 的自然语言触发效果。

本地规模样本（每组 5 次，固定返回 10 条元数据）：

| 虚构需求数 | 响应体字节数 | 本地查询耗时中位数 |
| --- | --- | --- |
| 10 | 1777 | 0.693 ms |
| 200 | 1817 | 9.897 ms |

这是本地索引读取的有限样本，不是总会话耗时或计费 token 对照；没有测量真实账单 token。查询时间随元数据量增长，返回内容按分页保持有界。
