- 本次仅验证了两个项目的只读查询，没有验证新增、修改、删除。

## asynctest-mind

用途：以思维导图形式编写和维护正式测试用例；用户指定需要时使用。

2026-09-20 已通过 `mind_read_file` 读取用户指定的历史 `.amind` 文件，查看整体结构及部分详细分支；未修改历史文件，未验证写入能力。参考信息见 [用例规范](test-cases.md)。

编辑前确认目标文档；多个窗口同时打开时明确目标窗口。按工具说明读取、编辑、保存和结束 Agent 会话，不能把内存编辑成功等同于文件已保存。

## 连接排查

全局配置决定启用哪些服务；成功连接、完成工具发现后，工具才可能提供给当前会话。设置开关开启不能单独证明连通。

若工具不可见，先检查可调用工具列表，再核对配置与启动日志；不要仅凭缺少工具就判断用户没有添加服务。曾出现把 Token 填入 `bearer_token_env_var` 导致启动失败的问题：该字段要求环境变量名称。调整认证参数后，本会话的读取已成功。

MCP 凭据保存在本机配置中，本仓库不保存或复制凭据。
