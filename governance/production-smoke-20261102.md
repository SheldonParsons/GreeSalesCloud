## 启动与登录边界

先按需读 AGENTS.md、README.md、环境和 UI 目录／维护约定，检查当前可用工具与目标模式。已有能力只有范围匹配时才复用；原 QA 专用入口和认证脚本不能仅替换 URL 就当成生产已验证方案。

优先 Chrome DevTools MCP 和独立 headless Chrome，不影响用户日常浏览器。仅使用用户交给本任务的生产登录身份，核对域名、当前账号和可见菜单范围；不搜索或试用旧 QA 账号、不改密码、不创建账号、不退出用户原登录、不接管日常 profile 或解除其占用。

用户已授权提前演练：如果能唯一确认其授权的生产已登录入口，并用已有受控方式在专用 headless 环境接续登录态，可以直接开始一次演练，不重复索要整轮只读许可。若实际已登录页面未提供、身份或目标不明确、无可用登录态，则先完成本地准备，向用户只询问必要的页面／连接信息，不虚报已运行。

无法隐式接续时说明具体原因，不默默切到可见操作。只有用户明确允许本任务显式使用现有页面时才这样做。截图回传不等于可见浏览器授权。登录材料只在本机受控位置使用，Cookie／Token／原始会话不进入 Git、报告或跨会话消息。

## 只读范围

遍历当前账号实际可见的完整业务菜单层级，以菜单路径、路由及必要参数识别叶子页面，保留真实清单和重复入口关联。只覆盖本商用订单管理端，不扫描隐藏路由、不猜接口、不自动扩大到其他系统外链。

允许：菜单导航与展开、清晰的列表查询／筛选／重置／轻量分页、只读页签，以及有数据时抽样打开明确只读的查看／详情。每页优先完成默认加载与一次有意义且负载可控的查询；详情优先每个有数据且提供入口的页面抽样一条，不全量打开每行。

禁止：新增、编辑保存、删除、提交、审批、接单、确认、状态切换、导入、批量业务操作、权限／基础资料修改。导出、打印、下载和重报表生成不在本轮默认范围。按钮或页面已知会写业务状态、或其副作用不清楚时不盲点试探，记录跳过原因。正常访问审计和会话维护不视为业务增删改授权。

查询可能使用 POST；按实际业务语义和页面动作判断只读，不把所有 POST 一律拦掉，也不把所有 GET 都假定无副作用。以 UI 自然触发的请求观察接口，不独立猜测或重复重放未知请求。

## 并发与时长

本次用户明确希望扩大并发以缩短耗时，限于只读点检，不是压测。优先工具／独立页签级并发，不额外创建用户会话或自行组建代理团队。

建议先用 2 路确认工具能按 pageId 独立路由、页面及账号状态不串扰，再升到 4 路，稳定且有足够独立页面时最多 6 路。工具只支持全局活动页面、出现串页／互踢／明显延迟、429 或连续 5xx 时降并发或暂停受影响任务，不无限加压、不循环重试接口。每个工人绑定自己的页签、菜单和网络时间窗口；同一页不并发操作。

菜单覆盖优先于单页深挖：先覆盖叶子菜单展示与查询，再补有数据页面的只读详情。主动关闭本任务已经完成且持续轮询的临时页以避免累计请求，不能关闭或改动用户原页面及其他任务页。

## 页面和接口判断

- 页面：目标路由／标题正确，主体内容或合理空态出现，无白屏、异常弹窗、持续加载或影响使用的错误；查询确实完成，有记录时详情能够打开并对应选中记录。
- 空数据：正常空态及成功查询可以判为本项正常；详情记“未验证：无可查看记录”，不为造数据执行写操作，也不把详情功能报成已通过。
- 网络：观察本轮菜单加载、查询和详情自然产生的业务请求，区分 HTTP 状态、业务响应和加载错误。按真实响应约定判断，不固定猜 code 必须为某个数字；HTTP 200 的业务错误仍记录。
- 控制台：记录影响显示或查询的错误；不能把无关警告自动判为业务故障，也不能忽略实际导致页面失败的资源／脚本错误。
- 权限、登录失效、工具无法观察接口与真正页面异常分别列明；无法观察的内容不写“接口均正常”。
- 本任务是生产可用性点检，不是本期需求全量验收。通过结论限于实际菜单、查询及抽样详情，不推导写入、审批或全部业务规则正常。

Markdown 至少包括：

1. 演练／正式标识、时间及耗时、环境和入口、当前账号角色引用、已知版本／未知项、实际并发。
2. 发现菜单数、实际进入数、完成查询数、详情抽样数，正常空数据、异常、受限及未覆盖情况；计数依据一致，不以发现数当完成数。
3. 逐菜单表：菜单路径、页面／路由、展示、查询、详情、接口观察、结果、证据或限制。
4. 异常列表：操作、实际现象、相关接口状态／业务错误及必要真实截图。未归因不猜前后端，不自动提交禅道。
5. 未覆盖项和原因、演练发现的工具／登录／并发问题、今晚正式点检的准备建议。

每条记录及时保存，过程给出简短可核算进度，遇关键生产异常或范围问题及时通知用户。超过预算停止新工作并保留未覆盖清单，不为了全绿改结果。

原测试仓库有其他会话未提交内容，只提交本轮核对过的报告／证据和自身明确负责的文件；不修改现有业务用例、其他需求状态、通用配置、VeriForge 设计或知识库，不与其他会话并发暂存／提交。当前交接文件由治理会话维护，执行者在自己的轮次目录记录补充。
