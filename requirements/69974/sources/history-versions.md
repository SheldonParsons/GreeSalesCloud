## H1：25.04.30版本——基础销售审核

### 页面、权限及数据范围

- 入口为排产中心—销售审核，包含标准订单、非标订单两个子菜单。
- 无销售审核菜单权限：显示无权限页面；有父菜单权限但两个子菜单权限都没有：仍显示无权限页面；有其中一个或两个子菜单权限：只展示有权限入口；有权限无数据：展示无数据列表。
- 接口必须验证身份及菜单 / 子菜单 / 操作权限，身份验证失败返回错误码。
- 客户类型为格力（`customer_type = 1`）才显示销售审核，一级排产中心菜单同样受此约束。
- 数据对象为生产任务单。默认不勾选“显示已处理”，展示待处理、已驳回；勾选后展示全部状态，并非只显示已处理。
- 按订单类型分标准 / 非标入口；顶级组织隔离，同一顶级组织下总公司、分公司、子公司之间数据隔离；订单商品产品线匹配账号所在组织配置的产品线。

### 查询、重置与排序

- 商品型号、商品编码、订单编号、客户名称均为文本输入，控件规则引用全局说明。
- 四项默认空，空值查询全部；按输入内容做“包含”模糊匹配，多条件同时满足。
- 重置恢复默认查询条件，并立即按默认查询重新展示。
- 分页引用全局说明，无本面板具体页大小。
- 勾选或不勾选显示已处理，均按接单审核通过时间（原文又称生产任务单创建时间）倒序。

### 列表字段

| 字段 | 原型规则 |
| --- | --- |
| 订单编号、商品型号、商品编码 | 取订单及订单行对应值 |
| 订单数量 | 订单行商品总数 |
| 库存数量 | 库存功能提供，实时取；点击查看库存，按单机 / 整机展示不同内容；排产不做处理 |
| 未发订单 | 该商品在所有订单中的未发货数量；库存功能提供，实时取；排产不做计算 |
| 已排未完 | 库存功能提供基础数据并计算，实时取，计算说明见下 |
| 待处理库存 | 库存功能提供，实时取；排产不做计算 |
| 缺货 | 按下述公式计算 |
| 接单日期 | 订单接单审核完成时间截取年月日，原文称当时记录在订单动态 |
| 发货日期 | 订单预计发货日期 |
| 项目名称、客户名称 | 订单关联项目 / 客户名称；没有则空 |
| 生产用编码 | 订单行商品记录的生产用编码 |
| 排产状态 | 生产任务单对应状态 |
| 单机 / 整机 | 商品中心该商品型号的数据 |
| 生产批次 | 必填，只允许英文大小写字母和数字，不允许空格，长度 20；原文把数字写作“数字（整数）” |
| 生产数量 | 必填、正整数、无空格，长度 10；不能超过生产任务单下单数量或订单行商品总数；默认订单数量，可改 |
| 生产类型 | 非必填，默认生产，可选生产 / 库存返包 |
| 订单等级 | 非必填，默认 B，可选 A / B |
| 交货日期 | 默认订单预计发货日期，可改，不可选今天以前的日期 |
| 备注 | 全局输入规则，长度 30，与商品备注是不同字段 |

控件在行勾选后启用，未勾选禁用。原型另注明相关区域同操作列固定最左侧，并提到列表自定义组件提供右侧固定；具体固定范围需结合版式确认，不能凭这句话自行扩展到全部字段。

### 数量计算与已处理交互

- 原型计算段标题写“已排未发数量”，列表字段写“已排未完”，保留名称差异。
- ERP 数据是最小成品（单机）维度。单机或整机（无单机）直接展示 ERP 数量；整机（有单机）按配比折算：`整机数量 = min(单机a数量/x, 单机b数量/y, …)`。示例：配比 1:2，数量 300 和 400，结果为 200；没有给出非整除取整规则。
- 缺货数量：`库存 + 已排未完 − 未发订单 − 下单数量`；小于 0 展示计算结果（负数），大于等于 0 展示 0。
- 勾选显示已处理时，非待处理、非已驳回记录的行勾选禁用；生产批次、数量、类型、等级、交货日期、备注均禁用。

### 操作与状态

- 批量提交：无勾选禁用，有勾选启用；权限点控制显示。每次不得超过 20 条，原文允许在超量勾选或点击提交时提示“批量提交每次操作不能超过20条”。逐行逐项校验生产批次、生产数量，缺失分别提示“请填写生产批次”“请填写生产数量”。二次确认生产数量及进入生产环节后，根据选中内容创建任务明细；具体创建规则另引“提交”说明。本操作记录排产方式为套机排产（字段不在前端展示；另有单机排产）。
- 库存充足：无勾选禁用，有勾选启用；权限点控制显示。二次确认库存满足，以及确认后无法再排产；确认后结束后续流程，状态改为无需生产。
- 单机提交：仅单机 / 整机字段为“整机（有单机）”且有权限时显示；点击打开单机提交页，具体内容引用另页。

| 状态 | 状态表允许的操作 |
| --- | --- |
| 待处理、已驳回 | 提交、批量提交、单机提交、库存充足；单机提交另有整机（有单机）限制 |
| 待排产 | 修订 |
| 已排产、部分排产、无需生产 | 操作栏为 `—` |

原型另引用库存指标说明页面；未打开该外链，不把外链全文视为已读。单条提交、任务明细创建和单机提交详情不能由本面板独立补全。

## H2：25.05.30版本——补充生产基地和下单单位

### 标准订单优化

1. 列表增加生产基地：下拉、非必填、无默认值，枚举来自数据字典，维护方式同其他需维护字段。**此字段为信息传递用的预生产基地，不是最终排产实际基地。**
2. 查询增加下单单位：下拉多选，枚举为全部销售公司；默认空，空值查询全部；匹配订单的提货方，多查询条件同时满足。

### 非标订单

列表字段取值及功能同标准订单，引用标准订单说明。本版面板未重写 H1 全部规则。

## H3：26.08.30——按 MTO 整合方案重新设计

### 权限与入口

- 入口排产中心—销售审核；标准订单和非标订单 Tab 分别配置权限。
- 数据权限与管理端订单列表一致：`（部门监管 ∪ 渠道监管）∩ 产品线`。部门监管按订单创建人组织，包含下级；渠道监管按订单所属渠道网点；产品线匹配账号组织配置。
- 查看、提交与批量提交、库存充足及批量库存充足、单机提交均配置操作权限；具有提交 / 批量提交权限才可编辑列表对应字段。

### 状态和操作

| 需求计划明细状态 | 含义和操作 |
| --- | --- |
| 待处理 | 订单推送排产等待审核；查看、提交、库存充足；商品为套机时显示单机提交 |
| 已分单（无需排产） | 库存充足，流程结束；查看 |
| 已分单 | 记录排产方式、订单等级，进入后续生产链路；查看 |
| 已关闭 | 订单取消或流程终止；查看；这是 0830 历史描述，0930 PRD 另明确本期不涉及 |

本表还保留两条带“**本期不再这里展现**”备注的设计：审批评审单要求关联 Tracker `review_status=评审中` 且用户为审批人；修订要求开发状态为已处理 / 待维护返包文件且 Tracker `review_status=空闲`，二次确认发起修订。不能忽略“不在这里展现”的限定，把它们写成 0830 列表已开放的按钮。后面的操作表仍保留修订引用，属于原型内部待澄清之处。

### 查询

| 字段 | 限制 | 取源及匹配 |
| --- | --- | --- |
| 商品型号 | 文本 100，格式不限 | 当前需求明细商品型号，模糊 |
| 商品编码 | 文本 32，格式不限 | 当前需求明细商品编码，模糊 |
| 订单编号 | 文本 20，仅字母数字 | 所属订单编号，模糊 |
| 客户名称 | 文本 255，格式不限 | 所属订单客户名称，模糊 |
| 下单单位 | 文本 255，格式不限 | 所属订单顶级组织名称，模糊 |

默认分页，每页 20 条；按订单行创建时间降序。H1 的接单审核通过时间排序不能继续作为本版口径。H2 的下单单位“销售公司多选匹配提货方”也已被明确调整。

### 操作说明

- 提交、单机提交：打开提交抽屉，引用“点击这里查看”的详细说明。
- 批量提交：按行校验生产数量是否填写；本面板未重述 20 条限制，也未列生产批次必填，不能将早版的全部限制直接当作最新确定规则。
- 库存充足：二次确认后，把所选需求明细状态改为已分单（无需排产）。
- 修订：写“交互与详情页一致”，另引详细说明；与前述“不在这里展现”须共同看待。
- 显示已处理：默认不选；选择后仅展示需求计划明细审核时间非空的数据，包含需排产和无需排产两类。前一操作表把同样规则的控件写成“显示待处理”，后面独立小节及演示控件写“显示已处理”，记录为命名不一致，不自行改原文。
