## 2. 全局明细占比与局部构成占比

这是两套分母，必须分别维护。

### 2.1 明细表占比

```text
维度值占比 = 该维度值对应的咨询子单数量 / 全局筛选后咨询子单总量 × 100%
```

例如全局500单，A公司100单，则公司明细中A公司占20%。分页不会把分母改成当前页记录数。

### 2.2 局部环形图占比

选择某科室、销售公司、行业或项目用途后，构成图使用所选对象内部总量：

```text
局部构成占比
= 所选对象范围内某类型/产品类别的子单数量
  / 所选对象范围内子单总量 × 100%
```

用户确认例子：全局500单、A公司100单、A内某咨询类型20单。选择A后，该类型显示20%，不是按全局500计算成4%。该原则适用于科室、公司、行业、用途的局部构成图。

占比保留两位小数。使用具体产品大类、产品系列或咨询类型时，分子和局部分母应在相同对象和全局筛选上下文中。

## 3. 科室分析

### 3.1 科室归属

用户确认内部规则：一个科室接单后，后续不会再转到另一个科室。本期按接单科室归属，不设计跨科室转移或同一子单在多个接单科室重复计数的业务要求。

原型接单科室字段说明取「商经部技术人员答复」流程进度人员对应的科室。实际底层字段与人员映射未实测；不能把任意审批人的科室替换为接单科室。

空科室展示未由本次材料规定，不额外增加“必须显示未分配组”或“必须排除”的业务要求。

### 3.2 各科室咨询统计柱状图

| 项目 | 规则 |
| --- | --- |
| 图表类型 | 柱状图，每个科室一根柱子 |
| 默认指标 | 咨询量，按咨询子单数量统计 |
| 可切换指标 | 咨询量、按时答复率 |
| X轴 | 科室 |
| Y轴 | 咨询量模式为单量；答复率模式为百分比 |
| 排序 | 按当前指标值降序 |
| 提示 | 可查看对应科室及具体指标值 |

柱状图本身不需要先选择某个科室。科室就是每根柱子的分组维度。

科室咨询量按对应科室范围的子单统计。科室按时答复率的最终分母是该科室范围全部子单，包含未答复和超时；按时边界为工作日历累计≤72小时。完整公式见指标文档。

### 3.3 科室咨询类型构成图

- 原型为环形图，展示当前选定科室的咨询类型构成。
- 图内有科室下拉，选择后切换该科室的构成数据。
- 用户确认可选科室为所有答复过的科室。
- 原型描述默认“咨询单答复数量最大的科室”；没有额外确认并列时的优先顺序。
- 局部占比分母为所选科室内部的咨询子单总量。
- 提示展示咨询类型、数量与占比；原型示例可见类型图例及占比标注。

该局部下拉与顶部全局答复科室多选不是同一控件。已确认选项来源不因材料未提及而新增“必须随全局条件裁剪选项”的规则。

## 4. 产品分析

### 4.1 产品大类／产品系列切换

产品分析支持产品大类和产品系列两个口径，切换后按当前维度展示排名及对应明细名称。

原型使用横向条形图：

- Y轴为产品大类或产品系列名称。
- X轴为咨询数量。
- 按咨询数量从高到低排列。
- 悬浮提示显示具体咨询单量。

原型中列举离心机、螺杆机、多联机等仅是举例，不能当作完整产品字典；实际产品大类、系列仍取系统对应业务字段。

### 4.2 产品明细

| 字段 | 口径 |
| --- | --- |
| 产品大类/产品系列 | 随当前选择展示对应名称 |
| 咨询数量 | 该类别或系列的咨询子单总数 |
| 有效咨询量 | 对应范围总量减三种完结状态子单量 |
| 占比 | 当前类别/系列子单量÷全局筛选后子单总量 |

支持分页，默认按咨询数量降序。用户明确本期不需要「平均响应天数」列，旧文字中的该字段应删除；不能据此新增一个未定义的平均响应指标。

## 8. 行业与项目用途明细导出

### 8.1 导出范围
