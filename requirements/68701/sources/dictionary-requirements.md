## 3.30 本模块流程、状态与衔接

以下逐项转写已在线核对的正文，与用户第二、三张截图内容一致。

| 说明项 | 当前规则 |
| --- | --- |
| 页面标识 | systemDictionary |
| 办理角色 | 已获得数据字典菜单和操作权限的管理员 |
| 入口与权限 | 平台设置 / 数据字典；默认授权超级管理员，其余账号须明确获得菜单与操作权限 |
| 主流程及分支 | 查询类型 → 新增或编辑类型 → 选择类型维护字典项 → 配置启停/默认项/排序 → 保存并记录日志 |
| 状态及完成条件 | 类型及项启用/停用；当前有效记录加操作日志，无字典版本链；类型与项保存分别验证，不级联删除已使用数据 |
| 上下游输入输出 | 复用已有平台数据字典服务；与3.9.1内部业务标签分开，不自动替代奖项规则、流程节点或阶段状态编码 |
| 失败与留痕 | 无权限、重复、被引用、并发变化及服务失败均保留输入并不改有效记录；新增、编辑、删除、默认项变化和排序记录实际人、时间、前后值 |

## 字段及操作规则

| 字段 | 必填与长度 | 规则 |
| --- | --- | --- |
| 类型名称 | 必填，1–50字符 | 去首尾空格，类型名称唯一 |
| 类型编码 | 必填，1–100字符 | 字母开头，仅字母、数字、下划线，平台唯一；创建后只读 |
| 字典项名称 | 必填，1–50字符 | 同一类型内唯一 |
| 字典项值 | 必填，1–100字符 | 同类型内唯一，创建后只读；业务引用使用稳定ID/编码，不以显示名称关联 |
| 状态 | 必填，启用/停用 | 停用不影响历史显示；已引用项不可直接停用造成业务失效 |
| 默认项 | 复选框 | 每类型最多一个有效默认项；选新默认项时原子取消旧默认，停用/删除默认项前先调整默认选择 |
| 备注 | 非必填，最多500字符 | 类型、字典项共用规则 |
| 排序 | 系统维护 | 同类型内拖动或上下移动后保存次序；不改变项值及业务引用 |

- 类型有字典项或被引用时禁止删除；不做无提示级联删除。已引用项禁止删除，允许按权限改显示名称但不能改稳定值。
- 不自动导入演示枚举作为正式业务数据；字典为空时展示空态，不借通用字典放开修改稳定阶段码、投票分值或固定奖项名额。
- 页面长度为本次产品约束，开发需核对现有字段容量；接口更严格时先对齐，不通过前端截断保存。
- 验收覆盖类型/项新增编辑、范围内唯一、默认切换、引用限制、停用、排序、取消不保存、权限与操作日志。
