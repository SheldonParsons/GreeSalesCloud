## 菜单管理：材料已经说明的内容

来源：[3.18.2章节全文](sources/menu-requirements-extract.txt)。

- 管理入口为“平台设置 / 菜单管理”，页面标识 `menus`；新增/修改打开 `menuEditor` 弹窗。涉及具备菜单管理权限的管理员，原型以超级管理员展示。

- 失败时保留输入，不改变有效记录；成功记录实际账号、对象、时间及关键前后值。正式服务端仍需事务与鉴权验证。

## 数据字典：材料已经说明的内容

完整逐项规则见 [在线需求转写](sources/dictionary-requirements.md)。

| 范围内能力 | 已有依据 |
| --- | --- |
| 列表与选择 | 左侧字典类型，右侧所选类型的字典项；按名称或编码查询、重置；空字典显示空态 |
| 类型编辑 | 名称必填1–50字符，去首尾空格且唯一；类型编码必填1–100字符，字母开头，仅字母/数字/下划线，平台唯一且创建后只读 |
| 字典项编辑 | 名称必填1–50字符且同类型内唯一；值必填1–100字符且同类型内唯一、创建后只读；引用采用稳定ID/编码，不用显示名称关联 |
| 状态与备注 | 类型与项启用/停用；停用不影响历史显示，已引用项不能直接停用造成业务失效；备注非必填，最多500字符 |
| 默认项 | 每类型最多一个有效默认项；选新默认时原子取消旧默认；停用/删除默认项前先调整默认选择 |
| 删除类型 | 有字典项或被引用时禁止删除，不作无提示级联删除 |
| 删除字典项 | 已引用项禁止删除；允许按权限更名，不能改稳定值；默认项另受默认选择限制 |
| 字典项排序 | 同类型内拖动或上下移动并保存次序，不改变项值及引用 |
| 取消与失败 | 取消不保存；无权限、重复、引用约束、并发变化或服务失败不改变有效记录，保留输入 |
| 权限及日志 | 默认授权超级管理员，其他账号需明确菜单与操作权限；记录实际人、时间、前后值 |

数据字典复用既有平台服务，与内部业务标签分开，不用它开放修改阶段码、投票分值或固定奖项名额。用户截图中的“审批流程 / 通过”不作为业务规则或必备数据。菜单、字典是否按赛届隔离仍无直接确认，页面显示第7届不能证明系统配置按届存储。
