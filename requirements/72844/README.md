## 公共准备

1. **登录与入口。** 打开 [QA 管理端](https://qasalescloud.gree.com/admin/login)，使用本轮获分配相应操作权限和数据权限的账号登录，核对页面为测试环境、当前账号与发版部署信息。进入【咨询单 → 咨询单知识库 → 知识库管理】。知识库管理控件以原型描述编写，QA 上线后核对实际名称。问答正向场景使用开通【李的订单-管理】角色菜单权限的账号，从【咨询单 → 项目技术咨询 → 销售公司咨询单 → AI 智能问答】进入。
2. **样本占用与复测。** 写入前在本轮共享执行记录查找指定 QA 环境和版本下的专用型号或定位关键词。确认无人认领后，登记执行人、批次、型号或关键词、实际知识编号及占用状态。待新建样本的实际编号在创建回读后补记。再按相同条件查知识库列表，命中时打开【查看】，将型号、关键词和系统编号与登记记录核对。若已被另一轮认领、存在同名且归属不清或命中多条，记录样本准备阻塞，等待负责人协调。复测仅复用本轮可确认归属的专用记录，按授权恢复准备条件中的原值并回读。结束后登记保留或释放状态。
3. **录入基础样本。** 完成样本占用检查后，按用例给出的【产品型号】或短关键词在知识库列表查询专用样本。缺样本时点击【新增知识】，把准备条件中的知识类型、系列、标准问题、型号、关键词、候选答案及来源字段填入同名控件。产品系列选择下表路径并确认。关键词逐项输入后按回车，标注留空的字段保持未填。点击【提交】后按同样条件查回，从唯一目标行【查看】记录实际知识编号及原字段。准备条件里的 A、B 指这里取得的实际编号。
4. **来源子单。** 在【咨询单 → 项目技术咨询】的【销售公司咨询单】页签，按下表的完整【咨询子单号】查询并回读编号。C1、C2 是已有 QA 测试子单，执行前核对当前账号仍可查到。C0 由数据准备确认当前 QA 库中无对应子单。[已有 QA 子单证据](../71652/page-discovery-20261021.md#新建成功后补齐的真实组件)
5. **对照数据。** 创建和更新时间的区分场景按给定型号预置跨日记录，D 取指定记录实际显示日期。十二个月正向场景在实施当天准备 A，并按当天回推开始日。例如实施日为 2026-11-30，区间为 2025-12-01 至 2026-11-30，缩短结束日到 2026-11-29 后核对 A 移出查询。分页场景先核对可见总数，权限场景先确认对照条目的数据范围。准备条件不满足时记录缺少的样本或配置。
6. **问答联动。** 每次点击【新对话】，复制用例里的完整问句，保留回答和可见来源。先确认问答接入本期知识库，以及如何核对同步完成和知识来源。新增后核对是否答出刚录入的资料编号。查询后先记下查看页的资料编号，再核对 AI 是否答出同一个。修改前后用同一个问题，改后应答出新号且回答中无旧号。删除前 A、B 都要能答，删除同步完成后核对 A 不再命中、B 仍能回答。只有笼统回答或缺少可核对的依据时，记待核验。
