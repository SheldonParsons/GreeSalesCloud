## 与验收有关的字段规则

- 列表按产品型号、知识名称、关键词和咨询子单号模糊查询。创建时间、更新时间均为日期区间，默认空，各自最长 12 个月。
- 搜索区的输入上限分别为产品型号 32、知识名称 255、关键词 255、咨询子单号 15。新建和编辑表单采用各自的字段长度。列表说明指定默认每页 20 条，样图中的分页数字为示例。
- 新建表单中，标准问题必填，长度 255。产品系列必填，沿用现有选择器。产品型号必填，长度 100，支持中英文、数字、符号及中间空格。候选答案必填，最长 500 字。
- 关键词必填，回车生成标签，已生成的可删除。每条知识最多 20 个标签，单标签最长 **15 字节**。
- 来源子单号和来源位置均选填，长度均为 255，来源位置格式不限。2026-11-23 用户确认，选填项可以各自留空。来源位置有值、来源子单号留空时，其他字段满足校验即可提交。填写来源子单号时，提交需校验子单是否真实存在。

## 公共准备

1. **登录与入口。** 打开 [QA 管理端](https://qasalescloud.gree.com/admin/login)，使用本轮获分配相应操作权限和数据权限的账号登录，核对页面为测试环境、当前账号与发版部署信息。进入【咨询单 → 咨询单知识库 → 知识库管理】。知识库管理控件以原型描述编写，QA 上线后核对实际名称。问答正向场景使用开通【李的订单-管理】角色菜单权限的账号，从【咨询单 → 项目技术咨询 → 销售公司咨询单 → AI 智能问答】进入。
2. **录入基础样本。** 先按用例给出的【产品型号】或短关键词在知识库列表查询同一专用样本。缺样本时点击【新增知识】，把用例准备条件中的知识类型、系列、标准问题、型号、关键词、候选答案及来源字段填入同名控件。产品系列选择下表指定路径并确认。关键词逐项输入后按回车，标注留空的字段保持未填。点击【提交】，回列表按同一条件查询，从唯一目标行【查看】记录实际知识编号及原字段；准备条件里的 A、B 指这里取得的实际编号。已有专用样本仅在字段、时间及授权状态均匹配时使用，复测前由数据准备恢复所需状态。
3. **来源子单。** 在【咨询单 → 项目技术咨询】的【销售公司咨询单】页签，按下表的完整【咨询子单号】查询并回读编号。C1、C2 是已有 QA 测试子单，执行前核对当前账号仍可查到。C0 由数据准备确认当前 QA 库中无对应子单。[已有 QA 子单证据](../71652/page-discovery-20261021.md#新建成功后补齐的真实组件)
4. **对照数据。** 日期场景按给定型号预置跨日记录，步骤中的 D 取指定记录实际显示日期。分页场景先核对可见数据总数，权限场景先由负责人确认两条专用条目的数据范围。场景准备条件不满足时记录缺少的样本或配置。
5. **问答联动。** 各场景直接给出要录入的标准问题与候选答案，以及问答框中要发送的完整问句。问句不含候选答案识别码。新增、编辑、删除前后按场景开启新对话，使用记录的知识编号、回答中独有的资料编号或可见来源核对命中。执行前确认该入口接入本期库、同步时点或状态和可观察的检索依据。缺少可核对依据时，问答检查记为待核验。
