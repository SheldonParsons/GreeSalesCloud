### 客户端批量生成与附件

- 入口：技术咨询—咨询单列表—新建咨询单，本次所选页面为非标产品选型。
- 默认选择“否，手工填写卡片”；选择“是，Excel批量生成卡片”后可导入。每行需求生成一张卡片，追加到当前咨询单，导入不等于提交。
- 导入成功的卡片可以修改、编辑，排列在已有卡片下方。切换填写方式保留手工与批量生成的已有卡片，并以当前咨询单整体统计数量。
- 正文规定本次上传数据与已有卡片合计最大50条，超出时提示修改。入口嵌图中的“最大20行”已由用户更正，见C01；导入时先按已有卡片加文件全部数据行校验数量，再进行其他判断，见C06。
- 产品大类、小类、系列均必填，字符长度各100，分别校验系统中存在及上下级归属；申请型号选填、长度100；选型要求必填、长度400；是否咨询核价为是/否选项，默认否，空值约束见C02。
- 同产品系列可以作为不同数据导入，生成不同卡片；六个导入字段全部相同才判为重复并忽略，见C04，不能仅按产品系列或型号判重。
- 导入前显示共有、可导入、无法导入的记录数；共有记录包含重复数据。存在失败记录时可下载失败说明，无失败记录时隐藏该按钮。失败说明包含序号、产品系列、申请型号、失败原因，文件名为“非标产品选型咨询单-导入失败原因说明-yyyy-mm-dd.xlsx”。
- 导入过程中展示执行状态，完成按钮不可点击。失败行与成功行并存时按C03处理。
- 项目信息的工程详细说明下方新增选填的技术要求附件：最多10个文件、每个50M以内，属于本次咨询主单；卡片附件仍属于对应卡片，两者不互相覆盖。管理端非标产品选型的查看、审批页增加该附件的查看和下载入口。
