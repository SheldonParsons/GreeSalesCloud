# 机型非标点：调整、配置状态转换与调整记录

状态：本地知识底稿 v0.1，2026-09-21；本期三项用户澄清已沿用，其他历史基线与空缺仍分别标识。未提交预览。

## 发起条件与调整内容

来源：H1-11。

- 历史可发起条件为机型非标点业务状态在待启用、已启用、已禁用内，且调整状态为 `-`、已通过或已驳回。调整审批中不再提供调整入口，改为关联调整审批单；审批权限另按当前节点判断。
- 进入当前型号＋单个非标点进行调整，无选择型号、无添加非标点入口。调整与新增驳回后的编辑是不同流程。
- 旧版可调整生产用编码、非标点及增减物料；非标点改变清空物料。F5 有 26.7.1 修订“生产用编码不可调整”，当前候选正文按该明确字段修订保留编码不可调整；旧联动说明单列在后文。
- 提交复核必填、格式、商品存在且已启用、非标点存在、组合重复等条件。重复排除当前记录的具体实现未写全，不将“与自身重复”作为必然失败规则。
- 校验通过且操作成功提示「机型非标点进入审批流程」。失败弹窗历史包含序号、商品型号、非标点、原因，确定关闭。

## 配置状态转换

来源：F5、F6；物料非空要求按 U2 用户确认。

| 调整前正式值 | 页面行为 |
| --- | --- |
| 已配置 | 状态字段回显已配置并置灰，不能改为未配置；不等于全部物料或整个页面锁定 |
| 未配置 | 状态可操作，未配置时两侧物料清空、禁用 |
| 未配置，临时选择已配置 | 两侧物料可编辑；不能立即把状态锁死，否则无法进行原型允许的回切 |
| 原未配置，提交前已配置再回切未配置 | 两侧物料及对应录入内容清空并禁用 |

提交结果为已配置时，至少增加或减少一侧有物料；仅一侧或两侧都有有效物料均满足非空条件，仍需通过其他校验。未配置→已配置且两侧均空，F6 的明确提示为「当前机型非标点增减物料为空」。用户 U2 是更普遍的非空规则，因此原已配置不能通过清空全部物料后提交绕过约束；该具体场景文案未单独给出。

原型括号中“增减物料都不为空”措辞不准确，完整正文为“不能全部为空”；本稿不改成两侧都必填。仅切换下拉框不等于提交、不等于正式生效。

## 审批生命周期与数据生效

来源：H1-11／H1-19、F7、F9；U3 已确认生效时点。

| 时点 | 调整状态 | 机型非标点及正式数据 |
| --- | --- | --- |
| 发起调整 | 审批中 | 原业务状态保持，正式配置和物料使用旧值；相关商品仍引用调整前数据 |
| 中间节点同意 | 审批中 | 整条审批未完，不能提前应用新值或启用 |
| 本期未配置→已配置的调整全部节点通过 | 已通过 | 业务状态为已启用，正式配置状态、物料改为本次获批内容，并触发模块 08 的订单通知 |
| 任一节点拒绝并驳回发起人 | 已驳回 | 原业务状态和正式数据保持，不写入被驳回申请内容 |
| 驳回后再次调整 | 新申请进入审批中 | 新增审批单，不覆盖原驳回单；最后获批的申请内容才生效 |

F7 写“发起调整后已启用”已经被 U3 明确纠正为全部审批通过后才已启用，不再重复询问时点。H1 曾保留“通过后状态不变”和“通过后待启用”的冲突，这两种旧口径不用于覆盖本期已确认的转换场景。

原已配置仅改物料、或未发生配置状态转换的其他调整是否也自动启用，尚缺当前适用范围，不把历史冲突静默选成一种答案，也不扩展本期通知为所有调整都推送。

## 调整记录

来源：H1-11、H1-17、H1-19。

- 字段包括调整字段、原值、调整后值、调整人、调整时间及查看审批单。
- 一次改多个字段按字段分多条记录，可共同关联同一张审批单；历史调整审批详情含本次调整／历史调整两个标签，字段结构相同，按调整时间倒序。
- 旧字段枚举在不同分支出现生产用编码、非标点、增减物料、新增非标点；H1 调整分支还包含商品编码，但其是否可操作与其他描述不完全一致，不恢复成当前可调整项。
- 新增非标点的历史记录为原值空、调整后值为名称。配置状态是否加入创建／调整记录，以及申请未生效时记录区域的展示范围，需要按本期日志要求核对。

## 暂存的旧生产用编码联动逻辑

以下仅用于保存历史变化，不作为当前已确认能力。来源：H1-11，F6 上半段仍保留相关旧文案。

1. 旧规则在生产用编码实际修改并提交时，查同型号、生产用编码不同于新值的其他机型非标点，已相同的条目排除。
2. 候选条目若存在不可调整状态，失败提示“用户存在不同生产用编码机型非标点审批中”。旧列举包括业务状态待启用／已启用／已禁用且调整审批中，以及业务审批中或已驳回且调整状态为 `-`。
3. 全部可调整时提示其他非标点生产用编码将一并调整，用户确认后在本次成功发起审批的前提下，为相关条目发起各自调整审批。
4. 本条提交失败不应发起其他条目的联动；未修改生产用编码时不触发该旧逻辑。

F5 明确禁止调整编码后，这套旧规则是否有其他入口继续使用不能凭残留文字确定，未来入库需留在历史变更说明而非现行操作流程。

## 待核对边界

- 换非标点时配置状态是否保留、是否重新决定锁定；回切后再次选已配置是否恢复旧物料。
- 无实质修改是否允许发起新审批。
- 配置状态进入调整日志及审批详情值绑定方式。
- 非配置转换场景的最终业务状态和通知范围。以上不是对 U3 时点的重复追问。
