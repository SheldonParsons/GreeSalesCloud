# 机型非标点：添加型号、驳回编辑与物料约束

状态：本地知识底稿 v0.2，2026-09-21；本轮已确认现行新增入口，其他规则保留各自证据状态，尚未提交预览。

## 添加型号的版本演变

来源：H1-09、H2-新增「录入生产用编码并带出商品信息」。

| 版本 | 入口与定位 |
| --- | --- |
| H1 初版 | 弹窗按类目／型号查询在库型号，展示类目、型号、商品编码，支持多选，已选型号默认勾选；确认加入配置列表，再从该型号的生产用编码列表必填单选 |
| H2 后续版 | 不再通过型号列表选商品，直接手工录入必填生产用编码；先校验平台商品库状态，再自动带出商品型号和商品编码，两项不可手工修改 |

H2 规则进一步写明：编码不存在或状态不可用时不给出商品信息且不可继续提交；修改为另一有效编码需重查并刷新商品信息；清空编码同时清空带出的型号、商品编码并提示必填。

**现行入口已确认（KQ-01／U5）：**2026-09-21 用户答复“是的，直接输入生产用编码”，确认沿用 H2 的输入编码并带出商品信息流程。H1 的勾选型号只作历史版本说明，不再作为当前入口待确认项。

## 配置行与提交

来源：H1-09、H2-新增；本期配置字段为 F3、U1、U2。

- 为目标机型添加非标点子行，子行包含非标点、配置状态、增加物料、减少物料及移除操作。删除／移除配置行同时移除该行物料，不等于删除名称库条目。
- 非标点必填、单选，选项取名称配置列表；同型号不能重复配置同一非标点，已配置项在继续添加时过滤。
- 切换非标点清空该行增减物料；是否同时重置本期配置状态尚未说明。
- 提交复核必填及字段格式、当前编码及商品的有效性、非标点有效性及重复组合。H2 按当前生产用编码重查商品状态及带出信息一致性，防止编码失效后仍使用旧带出值。
- 手工新增的组合重复按机型＋非标点检查，不因记录已有的业务状态不同而允许重复。用户本轮也明确导入已有商品编码＋非标点时失败；两个入口的组合表述及提示按各自来源保留，不再沿用旧导入覆盖逻辑，见模块 04。
- 条件全部通过且操作成功后提示「机型非标点进入审批流程」，业务状态为审批中，调整状态为 `-`。审批通过后的新增结果见模块 06，不套用调整审批结果。
- 新增失败弹窗历史字段为序号、商品型号、非标点、失败原因；确定关闭弹窗。历史“原文提示不为空”用于空值失败，文案可能写反，不能替代规则本身。
- 历史新增审批通过后产生该机型非标点的创建／调整记录，记录非标点原值为空、调整后值为名称，以及人和时间；本期配置状态是否单独产生创建记录尚未说明。

## 新增配置状态：已确认与原型规则

来源：F3／F4、U1／U2。

| 条件 | 规则及证据状态 |
| --- | --- |
| 新增初值 | 默认已配置；U1 已确认图 3 的“默认勾选为是”含义 |
| 取值 | 必填、单选，已配置／未配置；F3、F4 |
| 选择未配置 | 两侧物料清空并禁用；F3、F4 |
| 选择已配置 | 两侧物料可编辑；F3、F4 |
| 已配置提交 | 增减物料不能同时为空；U2 已确认。至少一侧有值不等于免除其他物料校验 |

历史“增减物料各自选填，不录也可提交”不再无条件成立；其正确衔接是按配置状态决定是否允许全空。未配置＋全空的字段组合符合原型，仍需满足其他提交条件。空物料错误在新增和编辑的精确提示尚未提供，不复制调整页文案。

## 新增驳回后的编辑

来源：H1-10、H2-编辑，及 F4。

- 仅新增业务审批已驳回的记录提供编辑，进入的是当前一行的型号＋单个非标点，无选择型号、无添加非标点入口。
- 历史允许维护当前行生产用编码、非标点和物料；改变非标点会清空物料。编码输入方式见下方冲突，不能直接沿用“同新增”三个字忽略差异。
- 提交沿用新增有效性与重复校验，通过后已驳回→审批中，调整状态 `-`，重新进入新增审批流程；失败则仍已驳回且不覆盖原正式保存内容。
- 取消／退出编辑不保存，记录内容及已驳回状态不变。
- F4 明确编辑配置状态可操作，选择未配置清空禁用物料，选择已配置开放录入。调整页“原已配置锁定”的规则不能无依据扩展到此编辑入口。
- 原已配置的驳回记录是否允许改回未配置，暂列待核对，不据截图默认双向无条件开放。

## 物料已有规则

来源：H1-09、H2-新增／编辑；本节均为历史基线，未把用例标记当作执行证据。

| 内容 | 历史规则 |
| --- | --- |
| 字段长度 | 物料编码文本输入框长度 100 |
| 匹配 | 对接物料管理精确匹配；无匹配提示「无匹配物料」；报废提示「物料已报废」 |
| 报废判断 | 信号代码为空、002、030时物料有效，其他代码判报废 |
| 输入后形式 | 校验通过生成物料编码－物料名称标签，可删除标签并维护数量 |
| 数量 | 手工录入默认 1，范围 1～100；超出或非数字受限／提示，具体控件行为未统一 |
| 增加物料条数 | 最多 10 个；第 11 个不可添加 |
| 重复 | 同一输入框重复及增减两侧相同编码均不允许，提示「物料编码存在重复」 |

## 暂不作为现行定论的细节

- H2 新增已改为手工录入生产用编码，但编辑分支仍写生产用编码“必填、单选，规则同新增”，且型号不可更换。编辑能否换编码以及如何限制到原型号，需要在模块确认时核对，不能混写成既可改机型又不可改机型。
- 旧用例写支持英文、数字，又写“商品编码首字符非数字时提示请输入物料”；该句的字段对象与格式规则含糊，先保留源描述，不断言所有英文开头物料都非法。
- H2 增加物料以回车确认，减少物料以失焦确认；本期部分原型写回车录入。语义校验规则可保留，触发手势暂不统一。
- 减少物料条数上限在历史用例中写“按不限制处理，待确认”。这是旧用例猜测，不写成知识库正式无限制规则。
- 同时提交多行时是否整体失败或部分成功不能从单行错误案例外推；批量导入部分成功有明确来源，手工新增事务策略没有同等明确依据。
