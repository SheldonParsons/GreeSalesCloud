# 机型非标点：配置非标点与历史数据处理

主维护项目：商用订单管理系统-管理端。本条说明页面上的“配置非标点”、它与“添加型号”的关系，以及历史数据处理。“配置非标点”的规则主要依据20260630历史用例中的机型非标点分支；历史初始化依据本期原型及用户确认。以下是需求与历史业务资料，不代表已通过本次系统测试。

## 1. “配置非标点”和“添加型号”分别做什么

点击“配置非标点”，在侧拉窗口中新增或修改非标点名称。保存名称后，“添加型号”页面就能从非标点名称列表中选择它；仅保存名称，不会在机型非标点管理列表中新增一条记录。

点击“添加型号”，输入生产用编码后，为对应机型选择非标点，再填写配置状态和增减物料。同一型号可以添加多个不同非标点，每条机型非标点记录分别保存自己的配置状态和物料。

录入表格可以按一个型号下挂多个非标点组织；保存后的管理列表按型号与单个非标点分别展示。型号、商品编码逐行展示，不把同型号全部非标点的物料混在一起，也不跨行合并展示型号和商品编码。

当前通过生产用编码反查商品型号和商品编码。列表展示粒度、手工重复检查和导入重复检查是不同概念，不根据界面形式推断数据库唯一键。

## 2. 配置状态属于机型非标点记录

配置状态显示在具体的机型非标点记录上，不是在“配置非标点”窗口里给某个名称统一设置的状态；它也不等于记录的业务状态或调整状态。

配置状态的通用规则主维护于当前知识条目“机型非标点：已配置时增减物料允许为空”（正文标题已扩充为“机型非标点：添加、编辑与配置状态规则”）。本条仅保留理解对象关系所需的说明：

- 取值为已配置、未配置，新增默认已配置。
- 用户于2026-09-22确认已配置时增减物料允许同时为空。
- 因而不能仅凭有没有物料自动判断配置状态，更不能把一个机型非标点的配置状态推广到所有同名非标点。

## 3. 历史记录统一初始化为已配置

本期列表原型“历史数据整理”明确：历史机型非标点对应的配置状态字段统一设置为已配置。用户已引用并确认该条，原型正文也已读取核对。

所有属于该历史初始化范围的机型非标点记录，均按该规则设为已配置，不因增加、减少物料为空就另设为未配置。

这是新字段的历史初始化要求，不是重新创建或审批这些记录。原文没有要求在初始化时补造物料、改写原业务状态，不能自行增加这些处理。

## 4. “配置非标点”窗口的操作规则

从机型非标点管理点击“配置非标点”，打开右侧侧拉弹窗。该弹窗独立维护非标点名称，重新打开能够看到已保存内容；后续添加型号使用其中的名称列表。

| 项目 | 规则 |
| --- | --- |
| 名称 | 必填，最长50字符；支持中文、英文、数字、标点及特殊符号 |
| 新增 | 新增一个空输入行，排在列表最前 |
| 数量 | 最多20条；达到20条后新增按钮置灰，不足20条时可继续新增 |
| 重名 | 新增或修改后的名称已存在时，提示“已存在非标点名称”，不保存 |
| 编辑 | 已保存名称可以修改；编辑时按钮为取消、保存 |
| 取消 | 不保存当前修改，恢复修改前内容 |
| 保存 | 保存当前名称；再次打开弹窗仍能看到已保存内容 |
| 删除 | “配置非标点”窗口只支持新增、修改非标点名称，没有删除入口 |
| 关闭 | 点击确定关闭弹窗，已经保存的名称保留 |

名称编辑保存后，历史需求要求所有关联该非标点的机型同步修改，订货端及管理端同步。该要求不等于历史订单快照也自动改名；历史订单的具体处理没有材料依据，不自行扩展。

“配置非标点”窗口没有删除名称的入口。“机型非标点管理”列表中的删除，则是删除某条机型非标点记录，是否允许删除要看记录状态，不能把两个页面的操作混为一谈。

## 5. 范围及未明确的细节

- “配置非标点”是历史已有功能，不应把整个窗口的操作归为69610本期新增。
- 历史用例对纯空格是否按空值处理、首尾空格是否裁剪、大小写是否算重名均标注待确认。本条只确定必填、最长50字符和名称唯一，不补造具体归一化算法。
- 历史用例有提交前校验“非标点不存在”的情形，但不能据此虚构用户可以通过“配置非标点”窗口删除非标点名称。提交时有效性检查与实际可执行的数据准备方式要分开。
- 名称变化的两端同步不能等同于配置状态调整后的订单通知，两者触发与作用范围不同。
- 本条不新增客户端管理入口、历史订单重算或数据库级删除策略。
