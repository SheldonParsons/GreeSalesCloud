# 机型非标点：状态、启禁用、删除与操作条件

状态：本地知识底稿 v0.3，2026-09-21；主要为 H1 历史基线，第三轮已确认两个删除条件，尚未完成模块全文确认，未提交预览。

## 业务状态基础

来源：H1-07，H1/H2 新增及编辑分支。

- 添加型号提交或有效导入后，业务状态审批中、调整状态 `-`。
- 新增审批全部通过，历史结果待启用；驳回为已驳回，编辑重提后回审批中。
- 待启用经启用变已启用；已启用经禁用变已禁用；已禁用经启用变已启用。
- 删除机型非标点记录与删除名称库条目不同：记录具有删除流程，名称库历史明确不提供删除。
- 本期配置状态是新增维度，不能从已配置推定业务已启用。本轮P1已明确：使用未配置机型非标点的订单无法发起，且该机型非标点无对应价格；不将此业务结果擅自变成选择控件必须隐藏或禁用。
- 调整提交与审批的独立状态及本期全部通过后启用，见模块 05。该内容不替代本模块单独的启用／禁用操作。

## 操作列矩阵及本轮删除修正

来源：H1-04；合并了按钮完全相同的状态组合。表内历史入口继续叠加菜单及审批角色权限；用户已确认的删除修正单独注明，不表示无权限用户也能执行。

| 业务状态 | 调整状态 | H1 操作列记录 |
| --- | --- | --- |
| 待启用 | `-`、已通过、已驳回 | 查看、启用、删除、调整 |
| 待启用 | 审批中 | 用户 U12 确认不允许删除；H1 原矩阵的删除项不再适用，其余历史操作为查看、启用、调整审批单 |
| 已启用 | `-`、已通过 | 查看、禁用、调整 |
| 已启用 | 已驳回 | 查看、禁用、调整、调整审批单 |
| 已启用 | 审批中 | 查看、禁用、调整审批单 |
| 已禁用 | `-`、已通过、已驳回 | 查看、启用、删除、调整 |
| 已禁用 | 审批中 | 查看、启用、调整审批单 |
| 审批中 | `-` | 查看、审批单 |
| 新增业务审批已驳回 | `-` | 用户 U13 确认允许删除，既有编辑重提保留；结合历史分支为查看、审批单、编辑、删除，审批单访问仍按角色权限 |

能够从多处分支确认的历史关系是：业务待启用／已启用／已禁用且调整不在审批中时可发起调整；调整审批中改为查看调整审批单。本轮已明确待启用＋调整审批中不可删除、新增审批已驳回可删除；其他按钮可见性继续按原有权限与来源核对。

## 单条启用

来源：H1-13。

- 入口要求当前业务状态待启用或已禁用。
- 二次确认文案：“启用后，对应机型即可选择非标点进行下单，请确认，是否继续启用？”按钮为取消、启用。
- 点击取消关闭弹窗，不改变状态。
- 确认时再次核验数据仍存在、型号仍在当前商品库、当前状态仍允许启用、对应非标点仍存在。提交前看到按钮不代替执行时复核。
- 失败分别记录为数据已不存在、没有此数据权限、当前状态不允许、当前非标点不存在等；历史用例将型号不在商品库映射为权限类提示，不据此推导后台权限实现。
- 全部通过且执行成功提示“非标点数据启用成功”，业务状态已启用，对应机型可选择该非标点下单。

## 单条禁用

来源：H1-13。

- 当前业务状态已启用时提供禁用；有二次确认，取消不修改。
- 执行时复核数据存在、型号在当前商品库、当前状态仍已启用、关联非标点存在。
- 成功提示“非标点数据禁用成功”，业务状态已禁用；失败保留对应数据／权限／状态／非标点原因。
- 现有材料未充分说明禁用对已创建订单、在途审批、历史订单明细的作用，不把“禁止新选”延伸为历史订单自动删除或失效。

## 批量启用与禁用

来源：H1-14。

- 勾选多条后执行批量操作，二次确认、各行校验条件与单条相同。
- 批量启用行要求待启用或已禁用；批量禁用行要求已启用。执行瞬间状态变化应按当时状态判定各行结果。
- 结果弹窗显示成功 X 条、失败 Y 条，以及失败列表中的序号、商品型号、非标点、原因；允许混合成功与失败，关闭结果后列表刷新成功行。
- “未选记录时提示请先选择记录”在历史用例中标了待确认，不作为已定提示文案。

## 单条与批量删除

来源：H1-15、H1-16。

- 历史删除分支允许业务待启用／已禁用且调整状态 `-`／已通过／已驳回删除；业务已启用或新增审批中不允许删除。
- **用户已确认（U12）：**业务待启用且调整状态审批中，在该审批尚未结束时不允许删除记录；不能依赖旧矩阵的删除项放行。
- **用户已确认（U13）：**新建机型非标点申请被驳回后，业务状态已驳回时允许删除，也可保留记录编辑重提。旧删除分支将新增已驳回列为不可删的文字已被本轮澄清修正；不是对调整审批驳回状态的笼统推断。
- 二次确认提示“删除后，数据不可恢复，请确认，是否继续删除？”；取消不删除。
- 确认时复核数据仍存在、型号仍在商品库、是否处于已启用或审批中等不可删状态。
- 数据已被删除时提示“此数据已删除，不可重复删除，请检查!”；型号不在商品库为权限类失败；不可删状态提示“无法删除当前数据，请检查！”。
- 成功提示“删除机型非标点数据成功”，该机型非标点记录从列表移除，不可恢复。不能外推名称库条目或历史审批单也一并删除。
- 批量删除沿用单条校验，按行汇总成功／失败；失败明细包含序号、型号、非标点及原因，成功记录被移除，失败记录不得按成功处理。

## 已解决冲突与剩余边界

1. **已确认不可删除：**H1-04 与 H1-15 对待启用＋调整审批中互相冲突，现按 U12 定稿为不可删除，保留旧出处用于追溯。
2. **已确认允许删除：**H1/H2 编辑分支与 H1 删除分支对新增已驳回记录互相冲突，现按 U13 定稿为可删除，不再悬置。
3. **执行条件与入口一致：**应使用本轮确认的业务条件，不能用历史提交校验的简写绕过待启用＋调整审批中不可删规则，也不能据旧分支拦截已确认可删的新增已驳回记录。其他权限及数据有效性校验保留。
4. **配置状态对操作权限：**P1正文已补读，新增筛选、展示及订单发起约束明确；未见其要求增加“未配置不能启用／不能删除”，不自行添加。
