# 机型非标点：查询、列表与查看

主维护项目：商用订单管理系统-管理端。本条说明机型非标点管理的入口、查询条件、列表字段和“查看”页面。依据已读取的原型及历史用例；这些是业务要求，不代表已经通过本次测试。

## 1. 页面入口与权限

管理端入口为商品中心→非标点管理→机型非标点管理，进入后默认展示机型非标点列表。

进入页面需要相应菜单权限，且登录账号所在公司为格力；无权限的账号不展示该菜单或不可进入，公司非格力不可进入。新增功能还要求相应新增按钮权限。其他操作按记录状态、调整状态及角色权限提供，不能只看见按钮名称就认为所有人都可操作。

页面已有功能包括添加型号、批量导入、批量启用、批量禁用、批量删除、配置非标点，以及记录上的查看、编辑、启用／禁用、删除、审批单、调整、调整审批单等。具体操作规则由相应模块说明。

这些入口要求来自管理端资料，不自动复制为客户端也存在相同菜单或权限。

## 2. 查询条件

| 条件 | 填写与筛选规则 |
| --- | --- |
| 类目 | 级联多选，只允许选择商品授权给该账号的类目及其下级；上级类目不可选 |
| 型号 | 文本，最长100字符，输入字符不限制，模糊查询 |
| 商品编码 | 文本，最长100字符，输入字符不限制，模糊查询 |
| 生产用编码 | 文本，最长100字符，输入字符不限制，模糊查询 |
| 配置状态 | 下拉单选：已配置、未配置 |
| 非标点 | 下拉多选，选项为已维护的非标点名称列表 |
| 状态 | 多选：审批中、待启用、已禁用、已启用、已驳回 |
| 调整状态 | 多选：审批中、已通过、已驳回 |
| 更新时间 | 选择时间段 |

例如授权到某个三级类目时，可以选择该三级类目及它下面的四级类目，上级类目不可选。

点击“查询”按当前条件显示记录；点击“重置”清空过滤条件并刷新列表。配置状态只有单选，不能照搬“状态”“调整状态”的多选规则。

列表中的调整状态初始可以显示“-”，但查询选项只按原型列出的三个值，不擅自添加一个可筛选的“-”选项。

## 3. 列表记录如何展示

列表按“一个型号＋一个非标点”分别显示记录。同一型号配置多个非标点时分成多行，型号和商品编码逐行显示，不跨行合并。每行只显示该机型非标点对应的配置状态和物料。

| 字段 | 展示要求 |
| --- | --- |
| 复选框 | 支持选择单行、全选和取消全选，用于批量操作；具体可操作范围仍按权限和状态判断 |
| 操作 | 根据角色权限、记录状态和调整状态显示对应按钮 |
| 状态 | 展示当前机型非标点的业务状态，文字完整显示；颜色按UI设计 |
| 调整状态 | 文字完整显示，以颜色区分；初始无调整时显示“-” |
| 类目 | 原型字段说明取关联型号的系列，最长显示30字符；超出省略，鼠标悬浮显示完整信息 |
| 型号、商品编码、生产用编码 | 每项最长显示30字符；超出省略，鼠标悬浮显示完整信息 |
| 非标点 | 显示当前非标点，完整展示 |
| 配置状态 | 文本显示当前记录的已配置或未配置 |
| 增加物料 | 显示“物料编码－物料名称×数量”，最多显示5个组合；超出省略，鼠标悬浮显示完整信息 |
| 减少物料 | 同样显示“物料编码－物料名称×数量”，最多显示5个组合；超出省略，鼠标悬浮显示完整信息 |
| 创建人、更新人 | 最长显示5字符；超出省略，鼠标悬浮显示完整信息 |
| 更新时间 | 完整展示对应更新时间 |

不同状态是不同字段：配置状态不等于业务状态，也不等于调整状态。不能将“已启用”“审批中”等业务或流程状态填写到配置状态列。

历史用例曾将减少物料概括为名称和30字符，本条采用已读取列表原型的“编码、名称、数量，最多5个组合”说明。详情页的完整展示要求不覆盖列表的省略规则。

## 4. 点击“查看”

在具备相应访问权限的前提下，各业务状态的记录都有查看入口。进入的是当前记录的详情，不能跳到其他机型或非标点。

查看页为只读，历史资料不提供编辑、启禁用、删除入口；可以通过“查看审批单”跳转关联单据。

- 基础信息展示对应的数据状态标签。
- 机型非标点信息完整展示型号、商品编码、生产用编码、非标点、配置状态、增加物料和减少物料。
- 配置状态为文本，位于非标点之后、增加物料之前，完整显示已配置或未配置。
- 增减物料使用文本标签展示，多个物料可分别排列；内容和数量对应当前记录。
- 历史调整记录包括调整字段、原值、调整后值、调整人、调整时间，并能打开对应审批单。

配置状态是否需要单独写一条调整记录，按用户已确认的调整模块规则处理，不能仅凭详情增加了配置状态就推导出新增日志要求。

## 5. 调整审批未完成时显示什么

对已有机型非标点发起调整后，在审批全部通过前，列表和普通查看详情继续使用调整前已生效的数据。本次申请中的新配置和物料不能提前覆盖原记录。

调整审批单“机型非标点信息”中的配置状态也已由用户确认为显示调整前的值。普通详情、审批申请内容及调整记录区域要按各自规则理解，不把某一区域的展示结论随意套到全部字段。

已配置时物料允许为空，因此列表或详情看到空物料时，不能自动把配置状态显示成未配置。配置状态的完整填写规则由现有条目“机型非标点：已配置时增减物料允许为空”（正文为添加、编辑与配置状态规则）主维护。

## 6. 本期相关业务说明

历史机型非标点的配置状态统一初始化为已配置。此规则已在“机型非标点：配置非标点与历史数据处理”条目维护，不按是否有物料分配历史值。

列表原型明确：已标记为未配置的机型非标点没有对应价格，使用它的订单无法发起。判断依据是实际配置状态，不能仅因物料为空就自动判定未配置，也不能据此编造客户端选择控件必须隐藏或置灰。

未配置改为已配置并审批通过后的订单信息同步，按订单关联模块维护；本条不推导订单自动改价或重算。

## 7. 版本差异和未明确事项

- 生产用编码查询来自列表原型26.08.30段；配置状态单选查询和展示列来自26.09.30段，不能将全部查询功能都算成本期新增。
- 旧页面的商品编码查询占位符曾写生产用编码；本条按字段名称及约束说明区分两种编码，不以旧占位符改变查询对象。
- 更新时间在各操作下的具体触发时点尚未全部统一，不能把提交时间、审批时间、导入时间任意写成同一值。
- 本组材料没有明确列表导出、额外排序、配置状态筛选默认值或更多查询匹配算法，不自行增加这些功能。
- 精确视觉颜色、宽度及页面交互效果以实际UI要求为准，本条没有执行视觉验收。
