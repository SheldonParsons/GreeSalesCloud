# 机型非标点：启用、禁用与删除

主维护项目：商用订单管理系统-管理端。本条整理机型非标点列表中的启用、禁用、删除和对应批量操作。依据历史用例、列表原型及用户对冲突条件的确认；不代表已经通过实际测试。

这里的删除针对“机型非标点管理”列表中的具体记录。“配置非标点”窗口维护非标点名称，没有删除名称入口；两处操作不能混为一谈。

## 1. 业务状态与配置状态分开

添加型号提交或有效导入后，机型非标点业务状态为审批中，调整状态为“-”。新增审批全部通过后为待启用；驳回后为已驳回，可编辑重提。

单独的启禁用操作使业务状态按以下方式变化：

- 待启用→启用成功→已启用。
- 已禁用→启用成功→已启用。
- 已启用→禁用成功→已禁用。

配置状态只有已配置、未配置，不等于业务已启用或已禁用。已配置时物料可以同时为空；不能用物料是否为空推断业务状态。

原型明确使用未配置非标点的订单无法发起且该项没有对应价格。不能因为某条记录业务已启用，就忽略其配置状态及其他订单条件；也不能据此自行增加“未配置不能启用或删除”的规则。

调整审批可能改变业务状态，其明确场景由“机型非标点：调整与审批生效”主维护，不替代这里的单独启禁用操作。

## 2. 列表中的操作条件

以下按历史操作矩阵整理，并纳入用户已确认的两项删除修正。仍需叠加账号权限；审批单是否可查看、是否可审批分别按角色判断。

| 机型非标点业务状态 | 调整状态 | 操作条件 |
| --- | --- | --- |
| 待启用 | “-”、已通过、已驳回 | 查看、启用、删除、调整 |
| 待启用 | 审批中 | 查看、启用、调整审批单；用户明确不允许删除 |
| 已启用 | “-”、已通过 | 查看、禁用、调整 |
| 已启用 | 已驳回 | 查看、禁用、调整、调整审批单 |
| 已启用 | 审批中 | 查看、禁用、调整审批单 |
| 已禁用 | “-”、已通过、已驳回 | 查看、启用、删除、调整 |
| 已禁用 | 审批中 | 查看、启用、调整审批单 |
| 新增审批中 | “-” | 查看、审批单 |
| 新增审批已驳回 | “-” | 查看、审批单、编辑、删除；用户已确认允许删除 |

调整正在审批时不再提供再次调整入口。业务已启用、或新增审批正在进行时，不能按上述规则删除记录。

旧操作矩阵曾在“待启用＋调整审批中”列出删除，用户明确纠正为不可以。旧删除分支曾写新增已驳回不能删除，用户明确纠正为可以；这两处旧文字不再用于判断现行结果。

## 3. 单条启用

当前业务状态为待启用或已禁用，且账号有对应操作权限时，可以发起启用。

点击启用先二次确认。历史文案为“启用后，对应机型即可选择非标点进行下单，请确认，是否继续启用？”，按钮为取消、启用。取消只关闭弹窗，不改状态。

确认执行时再次检查：

1. 记录是否仍存在。
2. 商品型号是否仍在当前商品库及账号可操作范围。
3. 当前状态是否仍为待启用或已禁用。
4. 对应非标点是否仍存在。

不能因为打开弹窗时状态正确，就忽略确认时数据已变化。全部检查通过且执行成功后，提示“非标点数据启用成功”，状态变为已启用。

失败时保留对应原因：数据已不存在、没有此数据权限、当前状态不允许、当前非标点不存在。历史用例将型号不在商品库对应为权限类提示，这不等于已经查明后台权限实现。

启用提供订货使用的业务前提；前述未配置无价、订单无法发起及其他订单限制仍然适用，不把这段旧启用提示解释成无条件下单保证。

## 4. 单条禁用

当前业务状态为已启用且有权限时可以禁用。先二次确认，取消不修改。

执行时再次检查记录存在、型号仍在当前商品库及可操作范围、当前状态仍已启用、关联非标点仍存在。

成功提示“非标点数据禁用成功”，状态变为已禁用；失败时显示相应数据、权限、状态或非标点原因，不能将失败记录当成禁用成功。

现有材料未说明禁用对已创建订单、历史订单明细或在途审批的全部作用，不扩展成历史订单自动删除、失效或重算。

## 5. 批量启用与批量禁用

在列表勾选多条记录，点击对应批量按钮，二次确认后逐行执行同类检查。

批量启用要求该行状态为待启用或已禁用；批量禁用要求已启用。提交前若某行被他人改了状态，执行时按当时状态判断，不能继续套用勾选时的旧状态。

结果允许部分成功、部分失败。弹窗显示成功X条、失败Y条，失败列表包括序号、商品型号、非标点和失败原因。关闭结果弹窗后刷新列表，成功行体现新状态，失败行不能被记为成功。

未勾选记录时的准确提示在历史用例中标为待确认，本条不把“请先选择记录”写成已经确认的固定文案。

## 6. 单条删除

在满足权限和数据有效性条件时：

- 待启用或已禁用，且调整状态为“-”、已通过或已驳回，按历史规则可删除。
- 业务待启用、调整状态审批中，用户已确认不可删除，必须保留正在审批的记录。
- 新增审批被驳回、业务状态已驳回，用户已确认可删除；也可以选择保留记录并编辑重提。
- 业务已启用或新增审批中，不允许删除。调整审批中的其他组合按本条操作矩阵判断，不能绕过状态限制。

点击删除先提示“删除后，数据不可恢复，请确认，是否继续删除？”。取消不删除；确认后再次检查数据是否存在、型号是否仍在商品库及账号可操作范围、当前状态是否仍允许删除。

历史失败提示包括：

| 情况 | 提示 |
| --- | --- |
| 记录已被删除 | 此数据已删除，不可重复删除，请检查! |
| 型号不在当前商品库／无对应操作权限 | 没有此数据的权限，删除失败，请检查！ |
| 当前状态不可删除 | 无法删除当前数据，请检查！ |

成功提示“删除机型非标点数据成功”，对应记录从列表移除，不能恢复。原材料没有说连同“配置非标点”窗口中的名称或历史审批单一并删除，不能自行增加级联删除含义。

历史提交校验有些只简写“已启用／审批中不可删”，不因此绕过用户明确的调整审批中不可删规则，也不依据已作废文字拦截新增已驳回记录。

## 7. 批量删除

勾选多条后点击批量删除，先二次确认，各行沿用单条数据有效性、权限和状态检查。

结果按行汇总成功与失败，允许同一批次部分成功。失败明细列序号、商品型号、非标点及失败原因。

成功行从列表移除；失败行保留，不因其他行成功而误删。取消二次确认不执行本批次删除。

新增已驳回可删除及待启用且调整审批中不可删除的最新规则，同样不能被旧批量校验说明覆盖。
