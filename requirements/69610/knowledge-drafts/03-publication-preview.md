# 机型非标点：添加、编辑与配置状态规则

主维护项目：商用订单管理系统-管理端。本条在已有“已配置时增减物料允许为空”知识上更新扩充，保留原知识身份及原有有效规则。

适用范围：机型非标点添加型号、新增审批驳回后的编辑、配置状态和物料录入规则，以及已发布的空物料规则在导入和调整中的适用方式。相关历史需求包括64698、68209，本期增量为69610。内容来自需求材料和用户确认，不代表已经通过系统测试。

## 1. 添加型号与生产用编码

添加型号时，直接输入生产用编码，由系统带出对应商品型号和商品编码，不能沿用早期“先勾选型号再选编码”的入口作为现行规则。

输入编码先自动去除反引号及空格，再按修正后的值校验：必填、支持英文与数字、首字符必须为字母。编码及对应商品须存在并满足该入口的有效性要求；编码对应多个商品型号、编码已报废等情况不能继续使用。信号代码为空、002、030表示设备或物料有效，其他信号代码表示已报废。

型号、商品编码使用编码带出的结果，不允许手工任意修改。更换或清空生产用编码时，商品信息应同步重新查询或清空，不能保留上一次编码的结果。原型还明确，点击生产用编码的删除按钮后，该次输入对应的商品编码、型号、非标点和增减物料一并清除，只保留一行非标点录入；这不是删除已经保存的业务记录。

编辑页原型明确：生产用编码已禁用或未上架时提示当前生产用编码不可用。不同页面的校验不能仅用“同新增”概括而忽略原文差异。

## 2. 为机型配置非标点

一个商品型号最多添加10条非标点。非标点必填、单选，选项来自非标点名称库；同一型号继续添加非标点时，已经选择配置的非标点会被过滤。

每条非标点分别维护配置状态、增加物料及减少物料。切换非标点会清空该行增减物料；移除一行同时移除该行的物料配置。只剩最后一行时隐藏移除按钮。移除录入行不等于删除名称库中的非标点。

保存后列表按型号与单个非标点分别展示，各行物料属于各自非标点，不能相互串用。

## 3. 配置状态及空物料规则

配置状态必填、单选，取值为【已配置】或【未配置】。新增默认选中已配置；导入模板中配置状态默认空，必须填写。历史机型非标点的配置状态统一初始化为已配置，不按有无物料重新分配历史状态。

选择未配置时，增加物料和减少物料都清空并禁止填写。选择已配置时，两个物料输入框均可编辑。

**根据用户2026-09-22确认，选择已配置时，增加物料和减少物料可以同时为空，也可以只填一侧或两侧都填。** 其他必填字段、业务状态、权限等校验通过后，允许提交或导入；不能仅因没有填写增减物料而拦截，也不能因物料为空自动将已配置改为未配置。

| 操作 | 已配置且增减物料都空时的处理 |
| --- | --- |
| 新增 | 可以提交，进入新增审批 |
| 批量导入 | 可以通过物料是否必填这一项校验；其他校验通过后可导入，保留已配置 |
| 新增被驳回后的编辑 | 可以重新提交，继续原新增审批流程 |
| 调整时从未配置改为已配置 | 可以提交调整审批 |
| 原已配置记录调整时删除最后一项物料 | 可以提交空物料调整；审批完成前仍使用调整前的正式数据 |

允许空物料不代表允许无效物料，也不免除审批。此规则替代此前“已配置时至少填一种物料”“两侧都空则失败”的旧要求；旧截图中“当前机型非标点增减物料为空”的拦截不再用于阻止上述场景。价格计算、订单接收策略和通知格式不能仅根据这一改动推导。

## 4. 填写物料时的检查

- 增加物料和减少物料是各自的录入区域，原型文本框长度为100。
- 输入物料编码后对接物料管理精确匹配；不存在时提示“无匹配物料”，已报废时提示“物料已报废”。
- 通过校验后，以物料编码和物料名称组成标签，可以删除物料、维护数量。
- 手工录入的数量默认1，范围1～100；超出范围或非数字应受限或提示，具体控件表现不自行补造。
- 添加型号原型明确增加物料最多10个、减少物料最多10个；不能沿用旧用例对减少物料“不限制”的猜测。
- 同一输入框重复编码，以及增减物料两边使用相同编码，都提示“物料编码存在重复”，不能把重复内容作为合法配置提交。

## 5. 点击确定后的校验与提交结果

提交时复核必填项、格式、当前编码与商品有效性、对应型号是否仍在商品中心且启用、同型号生产用编码是否一致，以及非标点重复情况。

最新添加与编辑原型使用“生产用编码＋非标点”描述提交重复检查，已有记录无论何种状态都要检查。该页面表述与导入“商品编码＋非标点”的现有组合检查分别保留，不推断成同一个数据库唯一键。

**用户2026-09-22确认：手工一次添加多条非标点，只要其中一条校验失败，本次全部不提交。** 例如3条中1条重复、另外2条正确，3条都不提交审批，不先提交其中正确的两条。批量导入允许正确行继续导入，是另一种处理流程，不套用到手工添加。

全部检查通过且执行成功后，提示“机型非标点进入审批流程”，业务状态为审批中，调整状态为“-”。历史新增审批全部通过后的业务状态为待启用；不能把配置调整通过后的已启用直接套用到新增审批。

新增失败弹窗提供序号、商品型号、非标点及失败原因。点击确定关闭弹窗。材料中个别必填失败提示出现“不为空”之类措辞问题，保留必填含义，不将笔误直接作为统一错误文案。

历史资料说明新增审批通过后产生对应非标点的创建／调整记录，非标点原值为空、调整后值为名称，并记录操作人及时间；不能据此自行增加未提供的创建日志字段。

## 6. 新增审批被驳回后的编辑

新增审批已驳回的记录可进入编辑，编辑当前记录的型号与单个非标点，没有另选型号或添加非标点行的入口。

生产用编码是可编辑文本，型号和商品编码按编码带出；提交还需检查同型号编码一致。编码可编辑不能被解释为允许任意换成另一型号。

配置状态可编辑：用户已确认原已配置的新增驳回记录可以改为未配置，并清空、禁用物料。选择已配置时可填物料，也可以都不填；填写时继续执行物料校验。

点击取消或退出编辑不保存修改，原内容和已驳回状态保持。提交失败不覆盖原来保存的内容。提交成功后业务状态恢复审批中、调整状态为“-”，**继续原来的新增审批流程，不另外发起新的审批流**。这与“调整审批驳回后再发起调整会新增审批单”不同。

## 7. 明确保留的未定细节

以下信息尚未由材料统一说明，不能当成确定业务规则：

- 切换非标点时是否重置配置状态；改未配置清空物料后，再改已配置是否恢复旧输入。
- 减少物料的校验时机：同一原型既写回车录入又写失焦匹配，暂不任选一种。
- 物料首字符检查的原句使用“商品编码”字样，与支持英文数字的录入描述存在对象歧义，暂不认定所有英文开头物料都非法。
- 名称库、调整生效、审批权限、订单接收等完整规则分别由对应模块维护；本条不推导未提供的订单自动重算或人工提醒政策。
