# 机型非标点：审批单与审批中心

主维护项目：商用订单管理系统-管理端。本条整理机型非标点新增审批、调整审批、批量审批添加，以及审批中心“我提交的”“我审批的”。来源为原型、历史用例和用户确认，不代表已执行测试。

添加与编辑主规则、调整的生效规则分别引用已有对应条目。本条维护审批权限、表单、单据查询及流程结果之间的关系，不把同一个规则另建成相互独立的版本。

## 1. 区分单据类型和状态

新增机型非标点审批单处理新增申请，调整审批单处理已有记录的修改。两者不是同一种单据，驳回后的再次提交方式也不同。

| 字段 | 含义与值 |
| --- | --- |
| 配置状态 | 已配置、未配置，描述这条机型非标点的配置选择 |
| 机型非标点业务状态 | 审批中、待启用、已启用、已禁用、已驳回 |
| 调整状态 | “-”、审批中、已通过、已驳回，描述调整申请进度 |
| 审批中心单据状态 | 审批中、已完结、已驳回，按整条审批流归类 |

审批中心显示已完结，表示流程全部通过，不等于每种业务记录都直接成为已启用。某位审批人完成自己的节点，也不表示整条流程已完结。

## 2. 使用哪个审批流

按审批流的适用组织／是否全局，取得覆盖提交人所在组织的生效审批流。

| 单据 | 流程名称 | 流程key |
| --- | --- | --- |
| 添加机型非标点 | 非标点管理-机型非标点-添加 | commodity_model_nonstandard_point_add |
| 调整机型非标点 | 非标点管理-机型非标点-调整 | commodity_model_nonstandard_point_adjust |

原型流程标题包含流程名称、添加机型非标点或非标点调整的业务说明及商品型号。型号最多展示前3个，以顿号分隔，超过部分以省略号展示。

上述为原型配置说明，不证明当前环境已经配置了对应生效流程。

## 3. 查看与审批权限分开

只有当前审批节点的审批人可以执行本单审批。非当前节点用户若有查看权限，看到的是只读表单，不能提前或代替当前审批人操作。

历史管理列表说明：非当前节点人不显示相应审批单操作按钮；驳回时节点审批人和发起人可见对应审批单。该入口规则与审批中心按本人提交、本人参与来展示记录的规则分别判断，不能把某个入口无按钮扩成所有入口都无法查看。

审批原型的页面数据权限结合相应页面及审批按钮权限，或已完成／当前节点审批人身份，并要求登录账号所在公司为格力。原文菜单路径有重复文字，本条只保留这些权限关系，不自行新增菜单名称。

当前节点审批人可见取消、提交按钮；其他有查看权限的用户看到关闭按钮。具体审批角色名单随实际流程配置，不由本条编造。

## 4. 审批表单与记录

基本信息包括提交人、提交时间、非标点类型、类型。非标点类型区分品类和机型，本条只整理机型非标点。类型区分新增、调整。

历史显示要求：提交人最长显示5字符，超出省略并可悬浮查看完整内容；提交时间和类型完整显示。

新增审批展示本次提交的型号、商品编码、生产用编码、非标点、配置状态及增减物料。调整审批展示对应机型非标点信息及本次／历史调整记录。

配置状态以文本完整展示。用户已确认：调整审批尚未结束时，“机型非标点信息”中的配置状态显示调整前的值。不能由这一项推定其他字段、调整记录和已办单据快照也一律采用相同取值。

审批动作必填、单选同意或驳回；审批意见为500字以内文本。提交前检查必填及格式，不通过时在对应参数展示提示。单条驳回意见是否必填尚未由现有材料明确，不能从下方批量驳回要求直接套用。

审批记录包括序号、节点名称、审批人、审批结果、审批意见及审批时间。历史规则为审批意见最长展示12字符，超出省略并悬浮完整；审批时间完整展示。

调整记录的字段、排序及配置状态是否另记一条，主维护于“机型非标点：调整与审批生效”；该条已保留用户确认与原型字段枚举的差异。

## 5. 审批结果与驳回后重提

| 情况 | 结果 |
| --- | --- |
| 新增审批所有节点同意 | 机型非标点业务状态由审批中变待启用 |
| 新增审批被驳回 | 业务状态变已驳回，可通过编辑修改后重新提交 |
| 新增被驳回后编辑并提交成功 | 恢复审批中，继续原新增审批流程，不另外新建审批流 |
| 未配置改为已配置的调整全部通过 | 调整状态已通过，正式数据更新，业务状态已启用，订单通知按对应模块处理 |
| 原已配置且已禁用，仅改物料数量的调整全部通过 | 业务状态仍已禁用，物料数量按获批值更新 |
| 调整审批被驳回到发起人 | 调整状态已驳回，原业务状态及正式数据不更新 |
| 调整被驳回后再次发起调整 | 新增调整审批单，不覆盖原驳回单 |

中间节点同意只推进审批流，不提前执行整条流程的最终结果。已配置允许空物料，也不免除这里的审批。

## 6. 批量审批添加

该历史功能面向新增机型非标点审批，不等同于批量调整审批。

只有当前用户能够审批的条目可以勾选；不可审批的条目不能勾选。选择后点击批量审批添加，打开右侧弹层并显示已选条数。

弹层包含型号、商品编码、生产用编码、增减物料及每行审批选择。每条默认选择通过，可以逐条改为驳回。

历史显示说明为：型号及编码最长30字符，增加物料最多展示5个编码－名称乘数量组合，减少物料最长30字符；超出省略并支持悬浮完整展示。此处为批量审批弹层的历史说明，不用管理列表的展示规则自动替代。

只要其中存在驳回项，就显示一份统一的驳回审批意见，必填且500字以内。提示为“存在驳回的机型非标点请录入驳回意见”。一次填写的意见用于本批次所有被驳回的条目。

全部选择通过时不展示驳回意见框。各条审批流全部通过后，该条业务状态才由审批中变待启用；驳回条目变已驳回。当前节点批量通过不表示后续所有节点也已经通过。

本期是否给该批量弹层增加配置状态列尚未明确，不因单条审批页增加字段就直接认定批量页也增加。

## 7. 审批中心“我提交的”

展示用户本人提交的机型非标点审批单和调整单，不包含其他人的提交。

- 全部：包含本人的审批中、已完结、已驳回单据，同一条不重复。
- 待审批：整条流程尚未结束的审批中单据。
- 已完结：所有审批节点已经通过的单据。
- 已驳回：已经被驳回的单据。

同一人既是提交人又参与审批时，可以分别以两种身份出现在“我提交的”和“我审批的”，不互相排斥。

## 8. 审批中心“我审批的”

范围包括当前轮到本人审批、以及本人已经审批过的单据。仅配置为未来审批节点、尚未轮到且未处理过的单据，不进入本人的“我审批的”；与本人完全无关的单据也不展示。

- 全部是待审批、已完结、已驳回记录的去重合集。
- 当前轮到审批人甲的单据显示审批中，归在待审批及全部。
- 审批人甲同意后仍在等待审批人乙，按历史用例，该单据仍在甲的待审批及全部，不因甲已经完成自己的节点就消失。
- 所有节点通过后进入已完结，不再在待审批。
- 甲驳回，或甲先同意、后续乙驳回，最终均在甲的已驳回及全部，不再在待审批。

这些归类依据整条审批流结果，不能只依据当前用户做过“同意”就列为已完结。

## 9. 审批列表和跳转

审批列表展示操作、标题、状态、创建人、创建时间。标题应区分新增与调整，不能串单。

同一单据在不同角色入口的标题、状态、创建人、创建时间一致；某标签没有记录时显示空数据，不混入其他状态或其他用户的记录。

“查看进度”和“查看表单”打开当前记录对应的单据，不跳到其他机型或其他审批类型。

## 10. 调整审批单“导出物料”

只有本次调整记录包含增加物料或减少物料变化时，才显示导出物料按钮。导出过程中按钮不可点击。

导出内容取当前调整单中增加物料、减少物料的调整后值。一个单元格有多个物料编码时，每个编码拆成独立一行。

表头为物料编码、物料名称；没有对应字段或值时留空。文件名为“商品型号-导出-yyyy-mm-dd-hhmm.xlsx”，其中时间取导出时刻。外部模板文件本次未实际读取和验证，不另造列、格式或公式要求。
