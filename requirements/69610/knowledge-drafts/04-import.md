# 机型非标点：批量导入与更新

状态：本地知识底稿 v0.1，2026-09-21；本轮首先核对的模块之一，未提交预览。

## 三步流程

来源：H1-12、H2-导入。

1. 上传文件：下载模板，上传指定格式 Excel；提供取消和下一步。
2. 点击下一步校验：按行判断，展示共有记录数、可导入数、无法导入数；共有数包含重复数据。存在失败时可下载失败原因说明，无失败时隐藏该入口。可返回上一步或执行导入。
3. 点击导入文件：只导入可导入行，成功记录进入审批中并创建审批流；失败行不进入本次成功导入记录。命中已有记录的具体审批类型待 KQ-02。

历史失败文件含序号、原行所有导入字段和失败原因；69610 新增配置状态后，新模板列位置、失败文件是否同步增加该列及旧模板兼容，尚未取得完整材料。

## 定位与必填字段的版本差异

| 来源 | 规则 |
| --- | --- |
| H1 初版 | 商品型号、商品编码、生产用编码、非标点名称均必填；以商品编码＋非标点绑定／更新；同时校验生产用编码属于当前型号 |
| H2 后续版 | 生产用编码、非标点名称必填；商品型号、商品编码非必填。按生产用编码反查型号和商品编码，即使模板填了型号／商品编码，也以反查结果用于配置 |
| F1、F2 本期 | 保留按生产用编码关联；增加配置状态必填，默认为空，可选择已配置／未配置 |

H2 按生产用编码＋非标点校验表内重复；命中系统已有记录时又用反查得到的商品编码＋非标点确定更新对象。这是两个判断层次，不能擅自合并为同一个数据库唯一键。

## 行校验

来源：H2-导入；与本期 F1、F2 相同的规则共同保留。

| 项目 | 条件 | 结果／已提供提示 |
| --- | --- | --- |
| 生产用编码 | 空 | 行失败：「当前生产用编码为空」 |
| 生产用编码 | 无法反查对应商品型号和商品编码 | 行不可导入，提示不能匹配对应商品信息；不自行编造更多细分文案 |
| 生产用编码＋非标点 | 同一文件重复 | 行失败：「当前生产用编码关联非标点重复」 |
| 非标点名称 | 空 | 必填失败；历史提示原文“当前非标点型号不为空”有明显措辞问题，原句不作为规范文案 |
| 非标点名称 | 名称库不存在 | 行失败：「当前非标点不存在」 |
| 增加物料 | 不存在／报废 | 分别提示「当前增加物料不存在」「当前增加物料已报废」 |
| 减少物料 | 不存在／报废 | 分别提示「当前减少物料不存在」「当前减少物料已报废」 |
| 增减物料 | 同行两侧编码重复 | 行失败：「当前物料重复」 |
| 物料展示 | 校验通过后反查名称 | 格式为物料编码－物料名称乘数量；减少物料数量未填按 1 处理。不能据此认定所有列、所有入口都默认 1 |

F1 片段还写生产用编码存在、对应型号存在等检查；H1 对商品授权、型号启用、多型号编码等校验更详细，但 H2 改变了定位方式。未读取完整最新原型前，不把 H1 已被替代的输入必填及字段校验原封不动恢复到 H2 流程。

## 配置状态新增规则

来源：F1、F2、U2。U2 已由用户确认，其他为本期原型。

| 配置状态／物料组合 | 当前整理结论 |
| --- | --- |
| 状态空，物料任意 | 必填失败：「当前配置状态为空」，不根据物料自动补状态 |
| 未配置，两侧空 | 符合该状态的组合，可继续其他校验 |
| 未配置，两侧均有物料 | 失败：「当前配置状态错误」 |
| 未配置，仅一侧有物料 | 原文“增减物料不为空”通常可解释为任一侧有值，先保留解释边界，不假称已经单独确认 |
| 已配置，两侧空 | 用户已确认不可导入；该入口具体错误文案待补 |
| 已配置，至少一侧有物料 | 满足非空约束，继续物料及其他字段校验 |
| 枚举外值或旧模板缺列 | 拒绝方式、兼容及提示未提供，暂不补造 |

图 1 允许物料为空时手工选状态的叙述不能再被解读为“选已配置后全空也可导入”，以 U2 澄清为准。

## 已有组合更新与条数上限

- **历史明确、当前待核对：**H1/H2 写系统已有商品编码＋非标点时更新增减物料，“有增加物料更新增加，有减少物料更新减少”，而不是新增另一条记录。该文字没有完整定义空侧究竟保留还是清空，也没有覆盖本期配置状态回退规则。KQ-02 本轮先核对更新是否仍允许及审批类型，细节随答复补齐。
- 手工新增碰到已有组合的行为是重复拦截，不能直接覆盖上述导入专属更新逻辑。
- **上限冲突：**H1/H2 总说明和本期 F1 为最多 100 条，历史上传提示仍为 1000 条；KQ-03 本轮核对现行上限。生产用编码＋非标点为一条记录，不能按型号合并后规避条数。
