# 机型非标点：批量导入与重复拦截

状态：本地知识底稿 v0.6，2026-09-22；已有组合导入失败已确认，单次上限按用户咨询产品后的最新反馈修正为 100 条，未提交预览。

## 三步流程

来源：H1-12、H2-导入。

1. 上传文件：下载模板，上传指定格式 Excel；提供取消和下一步。
2. 点击下一步校验：按行判断，展示共有记录数、可导入数、无法导入数；共有数包含重复数据。存在失败时可下载失败原因说明，无失败时隐藏该入口。可返回上一步或执行导入。
3. 点击导入文件：只导入可导入行，成功记录进入审批中并创建审批流；失败行不进入本次成功导入记录。用户已确认命中已有商品编码＋非标点的行导入失败，不更新原记录，不为该失败行发起新增或调整审批。

历史失败文件含序号、原行所有导入字段和失败原因；69610 新增配置状态后，新模板列位置、失败文件是否同步增加该列及旧模板兼容，尚未取得完整材料。

## 定位与必填字段的版本差异

| 来源 | 规则 |
| --- | --- |
| H1 初版 | 商品型号、商品编码、生产用编码、非标点名称均必填；以商品编码＋非标点绑定／更新；同时校验生产用编码属于当前型号 |
| H2 后续版 | 生产用编码、非标点名称必填；商品型号、商品编码非必填。按生产用编码反查型号和商品编码，即使模板填了型号／商品编码，也以反查结果用于配置 |
| F1、F2 本期 | 保留按生产用编码关联；增加配置状态必填，默认为空，可选择已配置／未配置 |

**本轮P2全文补读修正：**商品型号、商品编码非必填不等于可以填任意不匹配值。填写时必须校验与生产用编码相互对应，最终配置使用反查信息；旧用例中“均有值可导入”只能用于对应关系正确的输入。

H2 按生产用编码＋非标点校验表内重复；命中系统已有记录时又用反查得到的商品编码＋非标点确定更新对象。这是两个判断层次，不能擅自合并为同一个数据库唯一键。

**历史说明修正（KQ-02／U6）：**上述 H2“已有组合更新”不再作为当前行为。2026-09-21 用户明确：商品编码＋非标点已存在时导入失败，失败理由为“商品机型已有该非标点”。仍需区分表内重复与系统已有记录，不能因为两者都失败就认为定位组合及失败提示完全相同。

## 行校验

来源：H2-导入；与本期 F1、F2 相同的规则共同保留。

| 项目 | 条件 | 结果／已提供提示 |
| --- | --- | --- |
| 生产用编码 | 空 | 行失败：「当前生产用编码为空」 |
| 生产用编码 | 无法反查对应商品型号和商品编码 | 行不可导入，提示不能匹配对应商品信息；不自行编造更多细分文案 |
| 生产用编码＋非标点 | 同一文件重复 | 行失败：「当前生产用编码关联非标点重复」 |
| 商品编码＋非标点 | 系统中已存在该组合 | 用户已确认导入失败：「商品机型已有该非标点」；不覆盖原记录 |
| 非标点名称 | 空 | 必填失败；历史提示原文“当前非标点型号不为空”有明显措辞问题，原句不作为规范文案 |
| 非标点名称 | 名称库不存在 | 行失败：「当前非标点不存在」 |
| 增加物料 | 不存在／报废 | 分别提示「当前增加物料不存在」「当前增加物料已报废」 |
| 减少物料 | 不存在／报废 | 分别提示「当前减少物料不存在」「当前减少物料已报废」 |
| 增减物料 | 同行两侧编码重复 | 行失败：「当前物料重复」 |
| 物料展示 | 校验通过后反查名称 | 格式为物料编码－物料名称乘数量；减少物料数量未填按 1 处理。不能据此认定所有列、所有入口都默认 1 |

此前仅有F1片段及H1/H2用例，导入细分校验没有核对完整；本轮已按P2正文补齐下列规则，不将H1已被替代的型号／商品编码必填要求恢复到现行流程。

P2最新正文现已补读，以下直接按原型补入，不再归类为未读缺口：

- 生产用编码对应型号存在且启用、在账号商品授权范围内；生产用编码信号代码必须有效。不存在、未启用、无授权、已报废分别失败。
- **2026-09-22用户确认（U18／KQ-14）：**生产用编码对应多个库内商品型号的行失败，原因“当前生产用编码对应商品型号不唯一”；同文件其他正确行可以导入。例如10行中2行存在此问题，则这2行失败，其余8行可导入。P2“数据全部视为执行失败”不能解释为使整个文件的正确行也失败；其他映射冲突仍保留各自原句，不擅自扩大本例。
- 如填商品型号，检查与生产用编码对应；不同编码对应同型号、同编码对应不同型号均有失败检查。P2明确在“不同生产用编码对应同一个商品型号”处写“数据全部都要执行失败”；“同一个生产用编码对应不同商品型号”写执行失败，不能把全部失败措辞无差别扩到两项。
- 如填商品编码，检查与生产用编码对应；不同生产用编码对应同商品编码、同生产用编码对应不同商品编码均失败。各项源提示保存在[P2文字摘录](../sources/prototype-text/P2.md)。
- 导入过程中完成按钮不可点击；完成后展示实际成功／失败数，无失败不展示失败列表，有失败展示生产用编码、非标点、失败原因。
- 成功导入按添加型号审批流程汇总到审批表，再按机型非标点维度拆解审批和列表记录，业务状态审批中。
- P2仍有“当前型号已存在此非标点则创建人不更新”的旧片段，与U6已有组合直接失败冲突；继续按U6执行，不恢复覆盖路径。

## 配置状态新增规则

来源：F1、F2及2026-09-22用户最新修改U16；旧U2物料非空要求已撤销。

| 配置状态／物料组合 | 当前整理结论 |
| --- | --- |
| 状态空，物料任意 | 必填失败：「当前配置状态为空」，不根据物料自动补状态 |
| 未配置，两侧空 | 符合该状态的组合，可继续其他校验 |
| 未配置，两侧均有物料 | 失败：「当前配置状态错误」 |
| 未配置，仅一侧有物料 | 原文“增减物料不为空”通常可解释为任一侧有值，先保留解释边界，不假称已经单独确认 |
| 已配置，两侧空 | U16已确认可以为空；其他字段校验通过即可导入并进入审批，不改成未配置 |
| 已配置，有一侧或两侧物料 | 对填写的物料继续有效性、重复等校验，其余必填字段仍需正确 |
| 枚举外值或旧模板缺列 | 拒绝方式、兼容及提示未提供，暂不补造 |

按U16，已配置且物料全空可导入；旧稿基于U2写的禁止导入结论已作废。配置状态本身仍必填，不填状态的失败规则没有改变。混合7行示例中第7行“已配置＋物料全空”由失败转为成功，总数7、可导入5、无法导入2，失败明细不再包含第7行。

## 已有组合处理与条数上限

- **用户已确认现行规则：**系统已有商品编码＋非标点时，该行导入失败，失败理由“商品机型已有该非标点”。原物料、配置状态不通过本次导入覆盖。旧“有增加更新增加、有减少更新减少”只保留为已被本轮澄清否定的历史说明。
- 由于该行失败，原问题“更新后走新增审批还是调整审批”不再适用；不继续追问一个已被否定的覆盖路径。
