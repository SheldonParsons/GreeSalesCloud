# 机型非标点：访问、查询、列表与查看

状态：本地知识底稿 v0.2，2026-09-21；本轮已补读P1最新与历史需求段，原型规则和历史来源分别注明，未提交预览。

## 访问与授权

来源：H1-01。

- 历史管理端入口为商品中心→非标点管理→机型非标点管理，默认进入机型非标点列表。
- 进入权限要求有相应菜单权限且公司为格力；无菜单权限时不展示或不可进入，公司非格力不可进入。
- 新增功能要求相应新增按钮权限且公司为格力。其他按钮与状态及审批角色的组合见模块 06、07；不能仅根据按钮名称推导权限。
- 历史页面功能包括添加型号、批量导入、批量启禁用、批量删除、配置非标点、查看、编辑、启禁用、删除、审批单和调整审批单。

## 查询条件

来源：H1-02。

| 条件 | 历史规则 |
| --- | --- |
| 类目 | 级联多选；限商品授权的类目及其下级，上级置灰不可选。授权三级类目时可选该三级及下属四级类目 |
| 型号 | 文本，字符不限制，最长 100，模糊查询 |
| 商品编码 | 文本，字符不限制，最长 100，模糊查询；占位符写生产用编码与名称冲突，见待核对 |
| 生产用编码 | P1的26.08.30版本段明确新增；文本输入，最长100，字符不限制，模糊查询 |
| 配置状态 | P1的26.09.30需求段明确新增下拉**单选**，已配置／未配置；不能套用业务状态的多选规则 |
| 非标点 | 下拉多选，取后台录入的非标点列表 |
| 状态 | 多选：审批中、待启用、已禁用、已启用、已驳回 |
| 调整状态 | 多选：审批中、已通过、已驳回；不能据此假定查询选项包含列表显示的 `-` |
| 更新时间 | 支持时间段 |

查询按条件筛选；重置清空条件并刷新列表。

## 列表字段与显示

来源：H1-03、H1-09／H2-新增「提交成功后回列表」。

| 内容 | 历史规则 |
| --- | --- |
| 复选框 | 单行勾选、全选／取消全选，供批量操作 |
| 操作 | 按业务状态、调整状态及权限提供，见模块 06、07 |
| 状态、调整状态 | 完整展示，以不同颜色区分；调整状态初始显示 `-` |
| 类目、型号、商品编码、生产用编码 | H1 字段表写最长展示 30 字符，超出省略，悬浮显示完整；类目取关联型号的系列 |
| 非标点 | 后续提交回查用例按一个型号＋一个非标点拆行，各行独立展示型号和商品编码 |
| 配置状态 | P1最新段新增文本列，显示当前机型非标点的已配置／未配置 |
| 增加物料 | P1字段表明确显示物料编码－物料名称乘数量，最多5个组合，超出省略并悬浮完整 |
| 减少物料 | P1字段表同样明确编码－名称乘数量、最多5个组合，超出省略并悬浮完整；替代H1仅名称／30字符的较旧摘要 |
| 创建人、更新人 | 最长显示 5 字符，超出省略并悬浮完整 |
| 更新时间 | 完整展示；具体动作的时间口径未统一，不能用“提交／审批时间”替代确定定义 |

本轮以P1实际字段说明补齐物料组合与截断规则；历史回查用例的逗号分隔仅作结构参考。图8及P6、P7的“完整展示”对应详情／审批页，不能覆盖管理列表截断规则。

## 查看页

来源：H1-17；本期 P6 用户说明。

- 所有业务状态均可通过查看进入只读详情。历史查看页不提供编辑、启禁用、删除操作，只提供关联审批单跳转。
- 基础信息显示对应数据状态标签；机型非标点信息完整展示型号、商品编码、生产用编码、非标点及增减物料，多个物料以多个标签排列。
- 调整记录展示字段、原值、调整后值、调整人、调整时间，查看审批单跳转该条记录对应单据。
- **本期增量：**机型非标点信息增加配置状态。审批未通过时列表和普通详情继续使用正式旧数据；申请表单展示值来源另见模块 06。

## 本期版本说明与初始化

来源：[P1最新需求文字](../sources/prototype-text/P1.md)。

- 已选择／标记为未配置的机型非标点，后续使用它的订单**无法发起**，且该机型非标点**没有对应价格**。P1原文以暂无物料解释未配置的业务背景；按最新U16及已发布知识，物料全空也可以选已配置，不能根据物料是否为空自动改成未配置。
- 未配置记录调整补齐物料并审批通过后，将获批调整单的调整物料编码信息同步至订单管理模块。具体触发及推送字段见模块08。
- 历史机型非标点的配置状态统一设置为已配置，详见模块01；不按物料有无推断历史值。

## 版本差异与待核对

- P1正文已补读：配置状态单选筛选、文本列、历史统一初始化及订单发起／价格约束均明确。未读到的导出范围或其他控件细节不自行补造。
- 旧商品编码查询占位符与字段名冲突不改变查询对象；物料展示已按P1的编码－名称乘数量、最多5组合补齐，不再列作缺失规则。更新时间具体触发口径尚未统一。
- 本模块访问权限来自管理端历史用例，不能自动认定客户端也具有相同管理入口或公司限制。
