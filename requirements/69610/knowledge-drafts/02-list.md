# 机型非标点：访问、查询、列表与查看

状态：本地知识底稿 v0.1，2026-09-21；未获本模块确认，未提交预览。以下历史规则保留来源，现行适用性待模块核对。

## 访问与授权

来源：H1-01。

- 历史管理端入口为商品中心→非标点管理→机型非标点管理，默认进入机型非标点列表。
- 进入权限要求有相应菜单权限且公司为格力；无菜单权限时不展示或不可进入，公司非格力不可进入。
- 新增功能要求相应新增按钮权限且公司为格力。其他按钮与状态及审批角色的组合见模块 06、07；不能仅根据按钮名称推导权限。
- 历史页面功能包括添加型号、批量导入、批量启禁用、批量删除、配置非标点、查看、编辑、启禁用、删除、审批单和调整审批单。

## 查询条件

来源：H1-02。

| 条件 | 历史规则 |
| --- | --- |
| 类目 | 级联多选；限商品授权的类目及其下级，上级置灰不可选。授权三级类目时可选该三级及下属四级类目 |
| 型号 | 文本，字符不限制，最长 100，模糊查询 |
| 商品编码 | 文本，字符不限制，最长 100，模糊查询；占位符写生产用编码与名称冲突，见待核对 |
| 非标点 | 下拉多选，取后台录入的非标点列表 |
| 状态 | 多选：审批中、待启用、已禁用、已启用、已驳回 |
| 调整状态 | 多选：审批中、已通过、已驳回；不能据此假定查询选项包含列表显示的 `-` |
| 更新时间 | 支持时间段 |

查询按条件筛选；重置清空条件并刷新列表。

## 列表字段与显示

来源：H1-03、H1-09／H2-新增「提交成功后回列表」。

| 内容 | 历史规则 |
| --- | --- |
| 复选框 | 单行勾选、全选／取消全选，供批量操作 |
| 操作 | 按业务状态、调整状态及权限提供，见模块 06、07 |
| 状态、调整状态 | 完整展示，以不同颜色区分；调整状态初始显示 `-` |
| 类目、型号、商品编码、生产用编码 | H1 字段表写最长展示 30 字符，超出省略，悬浮显示完整；类目取关联型号的系列 |
| 非标点 | 后续提交回查用例按一个型号＋一个非标点拆行，各行独立展示型号和商品编码 |
| 增加物料 | H1 字段表写最多显示 5 个编码－名称组合，超出省略并悬浮完整；回查用例另要求多个物料以逗号分隔并包含数量 |
| 减少物料 | H1 字段表写显示名称、最长 30 字符并悬浮完整；回查用例另要求编码－名称及数量、多个逗号分隔 |
| 创建人、更新人 | 最长显示 5 字符，超出省略并悬浮完整 |
| 更新时间 | 完整展示；具体动作的时间口径未统一，不能用“提交／审批时间”替代确定定义 |

上述物料显示细节存在来源差异，尚未整理成唯一最终样式。图 8 的“完整展示”对应审批详情，不能直接覆盖管理列表的截断规则。

## 查看页

来源：H1-17；本期 P6 用户说明。

- 所有业务状态均可通过查看进入只读详情。历史查看页不提供编辑、启禁用、删除操作，只提供关联审批单跳转。
- 基础信息显示对应数据状态标签；机型非标点信息完整展示型号、商品编码、生产用编码、非标点及增减物料，多个物料以多个标签排列。
- 调整记录展示字段、原值、调整后值、调整人、调整时间，查看审批单跳转该条记录对应单据。
- **本期增量：**机型非标点信息增加配置状态。审批未通过时列表和普通详情继续使用正式旧数据；申请表单展示值来源另见模块 06。
