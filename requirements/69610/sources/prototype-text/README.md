## 对现有底稿的影响

1. 原 KQ-10“历史如何赋值”是阅读遗漏，按原型关闭，不能继续要求用户补答。
2. 原 KQ-11 将“选项是否可选”和“订单能否发起”混问。原型明确的是订单无法发起、无对应价格，不据此断言客户端具体控件置灰或隐藏。
3. 原 KQ-12“自动更新已有订单还是提醒人工处理”超出已定位的页面说明，本轮撤回，不作为用户必须补充的验收条件。保留原文的同步目标和字段，不补造订单范围、自动重算或人工提醒政策。
4. 历史统一已配置是初始化规则，与新增／提交时物料非空校验分开；不能按物料是否为空将历史数据分成已配置和未配置。
5. 当前正式 Mind 初稿缺少本次发现的列表筛选和历史初始化覆盖；先登记影响，本轮未修改用例或录入知识。既有“新申请”措辞要区分重新提交与创建新审批流，后续同步时应修正歧义。
