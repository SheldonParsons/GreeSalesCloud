## 本期原型明确的规则

- 非标产品选型咨询单的审批页，在「核价物料信息」中新增「AI识别核价」。上传支持 Word、Excel，也可直接粘贴核价方案文本。点击「下一步」进入「核对明细」，展示识别行数和待补充字段。粘贴路径还展示原文对照。点击「确认导入」后才将成功解析的数据回填到当前咨询单的核价物料清单。
- 需核价机型用于确定清单归属。多个机型或多份方案按对象及参考成品码分组，每组仅一条参考机型。生产用编码保留前导零、字母及后缀，名称和编码属同一项。正式型号或名称、单位需要系统匹配。
- 物料和设备分别识别增加或删减。不同编码替换时，旧编码生成删减行、新编码生成增加行，两侧各取自己的用量。同一编码有明确增减依据时取差额，增减数量均填正数。数量缺失留空、不默认填 1，缺编码、缺量或方向不明确的内容保留原文并标记待补充，不直接生成可回填行。

## 2026-11-23 用户确认

- **入口权限**。审批人有「核价物料信息」编辑权限即可使用「AI识别核价」，包括具备该权限的商经部直接答复人员。
- **原清单处理**。确认导入后，覆盖或追加均可接受。QA 按实际页面处理记录原有明细的去留。
- **重复编码**。同一份核价物料清单内，生产用编码不能重复，类型不同也按重复处理。用户提供的图 1 中，参考机型与增加设备录入同一编码后，页面显示「生产用编码存在重复」。该行内提示供参考，QA 采用其他能够实际阻止重复的方式也可接受。
- **待补充项拦截**。同批任一条明细缺数量、缺生产用编码或增减方向不明确时，核对页标记待补充，并阻止整次导入。完整明细也不能先回填。
- **商品编码**。生产用编码查询到有效数据时，由系统自动带出商品编码。本轮验收核对自动补充行为，带出的具体值按正确处理。
